# 第8章：マスターキーボードショートカット一覧

ATBCmder は、キーボードファーストのファイル マネージャーとしてゼロから設計されています。 すべてのファイル操作、ディレクトリ ジャンプ、ビュー変換、およびバッチ ユーティリティは、マウス操作なしで実行できます。 

オーソドックスな Commander の伝統とネイティブの Apple 人間工学の橋渡しをするために、ATBCmder は **デュアル マトリックス キーボード アーキテクチャ**を採用しています。すべてのコマンドは、従来の Commander ファンクション キー (`F1`–`F12`、`Insert`、テンキー) またはネイティブ macOS 修飾コードのいずれかを使用して呼び出すことができます。 (`⌘` コマンド、`⌥` オプション、`⇧` シフト、`⌃` コントロール)。

## 2. macOS 関数 (`Fn`) のキー ガイダンス

> [!重要]
 > ### Mac キーボードでファンクション キーを使用する方法
 >
 > デフォルトでは、Apple キーボード (内蔵 MacBook キーボード、Magic Keyboard、Touch Bar Mac を含む) は、一番上の物理行 (`F1` ～ `F12`) をディスプレイの明るさ、ミッション コントロール、スポットライト、ディクテーション、メディア再生、スピーカーの音量などのハードウェア コントロールに割り当てます。 
>
 > 従来の Commander ワークフローは `F1`–`F12` に大きく依存しているため、次の 2 つのオプションがあります。 
>
 > #### 方法 A: `Fn` キー コードを押し続ける (デフォルトのすぐに使用できる)
 > Mac キーボードの左下隅にある物理 **`Fn`** キー (または地球儀 🌐 キー) を押したまま、いずれかのファンクション キーを押します。 
>
 > * **`Fn + F3`**: Lister でファイルを表示
 > * **`Fn + F4`**: ファイルを編集
 > * **`Fn + F5`**: ファイルをターゲット パネルにコピーします
 > * **`Fn + F6`**: ファイルをターゲット パネルに移動します
 > * **`Fn + F7`**: 新しいディレクトリを作成します
 > * **`Fn + F8`**: ファイルを削除します
 > * **`Fn + Shift + F4`**: 新しいテキスト ファイルの作成と編集
 > * **`Fn + Alt + F7`**: ファイル検索を開く
 >
 > #### 方法 B: macOS 設定で「標準ファンクション キー」を有効にする (推奨)
 > ATBCmder を定期的に使用する場合は、関数行を切り替えて、`F1`–`F12` を押すと関数コマンドが直接トリガーされ、`Fn` を押し続けると明るさと音量の調整がトリガーされるようにします。 
>
 > 1. **macOS 13 Ventura、macOS 14 Sonoma、macOS 15 Sequoia**:
 > - ** アップルメニュー ➔ システム設定...** を開きます
 > - 左側のサイドバーで、**キーボード**を選択します。 
> - [**キーボード ショートカット...**] ボタンをクリックします。 
> - ダイアログのサイドバーで、**ファンクション キー**を選択します。 
> - **「F1、F2 などのキーを標準のファンクション キーとして使用する」** を **オン** に切り替えます。 
> - [**完了**] をクリックします。 
>
 > 2. **macOS 12 Monterey および macOS 11 Big Sur**:
 > - **アップルメニュー ➔ システム環境設定... ➔ キーボード**を開きます。 
> - [**キーボード**] タブで、**「F1、F2 などのキーを標準のファンクション キーとして使用する」** というラベルのボックスをオンにします。 
>
 > #### Touch Bar 搭載 MacBook Pro モデル
 >
 > * 左下の物理的な **`Fn`** キーを押し続けると、Touch Bar に仮想 `F1`–`F12` 行が即座に表示されます。 
> * あるいは、ATBCmder がアクティブな最前面のアプリケーションである場合、**システム設定 ➔ キーボード ➔ タッチ バー設定...** を構成し、**「タッチ バーに表示される」** を **「F1、F2 などのキー」** に設定します。 
>
 > #### 専用機能列を持たないコンパクトなキーボード
 >
 > * 専用の `F` キーのない 60% または 65% のメカニカル キーボードを使用している場合は、指をゆがめる必要はありません。 100% の動作同等性を提供する ATBCmder のネイティブ macOS 修飾子コード (`⌘C`、`⌥⌘V`、`⇧⌘N`、`⌘⌫`、`⌥⏎`) を使用します。

## 3. コンテキストスコープのショートカット アーキテクチャ

異なるアプリケーション領域間でのホットキーの衝突 (たとえば、メイン ファイル リスト内での検索とテキスト ファイル ビューア内での検索) を防ぐために、ATBCmder はすべてのショートカットを個別の階層コンテキストにセグメント化します。 

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          APPLICATION SCOPE: Main                            │
│  Global commands, panel navigation, window management, toolbar, power tools │
├───────────────────────────────┬─────────────────────────────────────────────┤
│  PANEL SCOPE: FilePanel       │  MODAL TOOLS SCOPES                         │
│  Active during directory      │  • Viewer      (Lister preview window)      │
│  table and thumbnail browsing │  • Editor      (Built-in code editor)       │
│  (marking, range selection,   │  • Differ      (Side-by-side diff viewer)   │
│  inline editing, space count) │  • FindFiles   (Multi-threaded file search) │
│                               │  • MultiRename (Batch rename engine)        │
└───────────────────────────────┴─────────────────────────────────────────────┘
```


 キーコードを押すと、**`HotkeyManager`** エンジンは次のように動作します。 

1. アクティブなフォーカスされたコンテキスト (`Viewer` または `FilePanel`) を評価します。 
2. 正確なバインディングが一致する場合、関連する `cm_*` コマンドが直ちに実行されます。 
3. ローカル コンテキストにバインディングが存在しない場合、キーストロークは `Main` コンテキストに正常にフォールバックします。 
4. まだバインドされていない場合は、標準のテキスト編集またはシステムのキーストローク処理が引き継ぎます。

## 6. プロのヒントとシステムホットキーの最適化

### 6.1 macOS のグローバル ショートカットの衝突の解決

特定のデフォルトの macOS システム ホットキーは、キー押下がデスクトップ アプリケーションに到達する前にインターセプトします。 Commander の俊敏性を最大限に発揮するには、競合する macOS ショートカットをカスタマイズまたは無効にすることができます。 

1. **スポットライト検索 (`⌘Space` とクイック検索)**:
 - デフォルトでは、`⌘Space` により Spotlight が有効になります。 ファイルのマーキングまたはパネル内検索に `⌘Space` を使用したい場合は、**システム設定 ➔ キーボード ➔ キーボード ショートカット... ➔ Spotlight** で Spotlight を `⌥Space` に再マッピングします。 
2. **ミッションコントロール (`⌃↑`) およびアプリ公開 (`⌃↓`)**:
 - macOS は、Mission Control に `⌃↑` および `⌃↓` を使用します。 ATBCmder では、`⌃↓` によって [ディレクトリ履歴] ドロップダウンが開きます。 **システム設定 ➔ キーボード ➔ キーボード ショートカット... ➔ Mission Control** で Mission Control を再割り当てできます。 
3. **アプリケーションの非表示 (`⌘H`)**:
 - macOS では、`⌘H` により最前面のアプリケーションが非表示になります。 ATBCmder は、`⌘H` または `⇧⌘.` を使用して、非表示のドットファイルを切り替えます。 `⌘H` で隠しファイルを厳密に切り替えたい場合は、macOS で「アプリケーションの非表示」を無効にするか、Finder 標準の `⇧⌘.` (`Cmd+Shift+Period`) を使用します。 
4. **ウィンドウの最小化 (`⌘M`)**:
 - macOS は、ウィンドウを最小化するために `⌘M` を Dock に割り当てます。 ATBCmder は、`⌘M` をバッチ マルチ名前変更ツール (`cm_MultiRename`) に割り当てます。 ATBCmder はメイン ウィンドウ内で `⌘M` をキャプチャしますが、`Ctrl+M` またはツールバーを介して Multi-Rename をトリガーすることもできます。 

---

### 6.2 トラックパッドとマウスの人間工学

外付けキーボードを持たないラップトップ ユーザーのために、ATBCmder はキーボード ショートカットと直感的なトラックパッド ジェスチャを組み合わせます。 

* **ピンチしてサムネイルをズーム**: サムネイル ビュー (`cm_ThumbnailsView`) で、MacBook トラックパッドをピンチインまたはピンチアウトして (または `⌃` を押したままスクロールして)、サムネイル プレビューのサイズを `48 px` から `512 px` まで連続的に変更します。 
* **2 本指で前後にスワイプ**: ファイル テーブル上で 2 本の指で左または右にスワイプして、フォルダー履歴を前方 (`cm_ViewHistoryPrev`) および前方 (`cm_ViewHistoryNext`) に移動します。 
* **ダブルクリック分割**: 垂直中央分割バーの任意の場所をダブルクリックして、パネルを正確に 50/50 の水平分割にリセットします。 
* **タブの中クリック**: フォルダー タブを中クリック (または 3 本指でタップ) すると、`⌘W` を押さずにすぐに閉じます。

### 6.3 環境設定でのキーバインドのカスタマイズ

上記に記載されているすべてのショートカットは、カスタマイズまたは再バインドできます。 

1. **`⌘,`** を押して (または **Configuration ➔ Options...** を選択して)、環境設定 ダイアログを開きます。 
2. サイドバーから [**ホットキー**] を選択します。 
3. **コンテキスト** ドロップダウンを使用して、構成する領域 (`Main`、`FilePanel`、`Viewer` など) を選択します。 
4. 検索フィルター ボックスを使用して、名前または `cm_*` ID でコマンドを見つけます。 
5. ショートカット ボックスをクリックし、目的のキーの組み合わせを押します。 そのコードがすでに別の場所に割り当てられている場合は、内蔵の衝突検出機能がすぐに警告します。 
6. [**適用**] をクリックすると、アプリケーションを再起動せずに変更が即座に有効になります。 

ユーザーのキーバインドは `~/.config/atbcmder/atbcmder_hotkeys.xml` (macOS では `~/Library/環境設定/atbcmder/`) に保存されます。 **`cm_ExportConfiguration`** を使用して、このファイルをエクスポートしてマシン間で転送できます。

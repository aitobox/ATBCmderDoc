# 第4章：万能ビューアーと内蔵エディター

従来のデュアルパネルファイル管理では、速度は検査速度に大きく依存します。 チェックサムを確認したり、構成行をチェックしたり、スクリーンショットをトリミングしたり、PDF を検査したりするためだけに、重量のある統合開発環境 (IDE) や肥大化したデスクトップ アプリケーションを起動すると、認知的摩擦やウィンドウの煩雑さが生じます。 

ATBCmder は、アプリケーション コアに直接組み込まれた統合されたマルチエンジンの表示および編集サブシステムを提供することで、この問題を解決します。 フォルダー間を移動する際のリアルタイムのインライン プレビュー、16 進モードでの詳細なバイト レベルのフォレンジック分析、ファイルの整理中にバックグラウンドで再生を続けるオーディオ プレーヤー、またはアトミックな構文認識コード エディターが必要な場合でも、ATBCmder を使用すると、キーボードを瞬時に制御できます。

## 1. ビジュアルクイックスタート: 即時ファイル検査と編集

ATBCmder は、ファイルの検査と変更を 2 つの異なるパラダイムに分割します。 

1. **反対側のパネル クイック ビュー (`Cmd+Q` / `Ctrl+Q`)**: 個別のウィンドウを生成せずに、非アクティブなパネル内にライブのデバウンス プレビューを直接埋め込みます。 
2. **専用のユニバーサル リスター (`F3`) および内部エディター (`F4`)**: 特殊なフォーマット エンジン、全文検索、メディア再生、構文ハイライトをサポートする独立した非モーダル ウィンドウを開きます。

## 2. クイック ビュー パネル (`Cmd+Q` / `Ctrl+Q` / `cm_QuickView`)

**クイック ビュー パネル**は、従来のファイル マネージャーの中で最も強力なワークフローの 1 つです。 クイック ビューは、数百のアイテムを含むフォルダーを検査するときにフローティング ウィンドウを開いたり閉じたりするのではなく、非アクティブなパネルを埋め込まれたコンテキスト ビューポートに変換します。 

![Quick View Panel](images/quick_view_panel.png)
 *図 4.1: ディレクトリ ナビゲーションの横にライブ構文で強調表示されたコードを表示する、反対側のパネルに埋め込まれたクイック ビュー。*

### 2.1 デュアルパネルプレビューの利点

クイックビューを有効にするには:

 1. アクティブなパネル内の任意のファイルまたはディレクトリに移動します。 
2. macOS の場合は **`Cmd+Q`** (`⌘Q`)、または **`Ctrl+Q`** (`cm_QuickView`) を押します。 
3. 反対側のパネルが通常のディレクトリ リストから **クイック ビュー コンテナ** (`QuickViewContainer`) に瞬時に切り替わり、カーソルの下に項目の内容が表示されます。 
4. `Cmd+Q` または `Ctrl+Q` をもう一度押すと、プレビューが閉じ、場所を失うことなく、反対側のパネルの前のタブとフォルダーのリストが復元されます。

### 2.2 100ms デバウンスされたリアルタイム更新

`Up` または `Down` 矢印キーを押したままにして、数千のファイルが含まれるフォルダーをすばやくスクロールすると、標準のファイル プレビューアーではユーザー インターフェイスがフリーズしたり、激しいディスク スラッシングが発生したりすることがよくあります。 

ATBCmder は、内部 **100 ミリ秒のシングルショット デバウンス タイマー** (`_quick_view_timer`) を通じてこれを解決します。 

- 行間を素早く移動すると、アクティブなファイル パスがメモリ内にステージングされます。 
- 大量のファイルの読み込み、構文解析、およびサムネイルのレンダリングは、項目上でカーソルが少なくとも 100 ミリ秒停止した場合にのみトリガーされます。 
- マルチギガバイトのメディア ディレクトリや生のディスク ダンプを参照している場合でも、スクロールは 60 フレーム/秒以上で完全にスムーズなままです。

### 2.3 `Tab` での対称フォーカスフリップ

デュアルパネル マネージャーでよくある問題は、パネルを切り替えるときにプレビューが失われることです。 ATBCmder のクイック ビューには **対称フォーカス反転** 機能があります。 

- 右パネルでクイック ビューがアクティブで、**`Tab`** を押してアクティブ フォーカスを右パネルに切り替える場合:
 1. 右パネルはすぐに通常のファイル テーブルを復元し、ファイルを操作できるようになります。 
2. クイック ビューは、自動的かつシームレスに左パネルに切り替わり、右パネルで強調表示されているファイルのライブ プレビューを表示します。 
- これにより、どのパネルで作業しているかに関係なく、中断のないナビゲーションと検査ループが維持されます。

### 2.4 インテリジェントなコンテンツルーティング

Quick View Container は、ファイル拡張子、MIME 署名、生のバイト ヘッダーを動的に検出して、最適なプレビュー エンジンを選択します。

### 2.5 メタデータ プロパティのフォールバック (`QuickViewPropertiesWidget`)

テキストまたはメディアとしてレンダリングできないディレクトリまたはファイル形式を強調表示すると、ATBCmder は自動的に **プロパティ フォールバック ビュー** (`QuickViewPropertiesWidget`) に切り替わります。 

```
┌────────────────────────────────────────────────────────┐
│  📁 release_builds                                     │
│  /Volumes/ExternalSSD/Projects/release_builds          │
├────────────────────────────────────────────────────────┤
│  Metadata                                              │
│    Full Path:      /Volumes/ExternalSSD/...            │
│    Size:           Directory (or 148,290,112 bytes)    │
│    Last Modified:  2026-09-06 14:10:22                 │
│    Last Accessed:  2026-09-06 15:02:18                 │
├────────────────────────────────────────────────────────┤
│  Permissions (UNIX)                                    │
│    Octal Mode: 0755                                    │
│    Owner:  [✔] Read  [✔] Write  [✔] Execute            │
│    Group:  [✔] Read  [ ] Write  [✔] Execute            │
│    Others: [✔] Read  [ ] Write  [✔] Execute            │

│  Checksums / Stats                                     │

 - **ヘッダー カード**: 高解像度のシステム アイコン、ファイル名、および親パスが表示されます。 
- **ファイル メタデータ**: 正確なバイト サイズ、人間が判読できるサイズ (`KB`、`MB`、`GB`、`TB`)、変更タイムスタンプ (`mtime`)、およびアクセス タイムスタンプを表示します。 (`atime`)。 
- **UNIX 権限マトリックス**: 4 桁の 8 進数の権限モード (`0755`、`0644`) を、所有者、グループ、その他の読み取り専用の 3x3 チェックボックス マトリックス (`rwx`) と並べて表示します。 
- **非同期バックグラウンド ハッシュ**: ファイルの場合、非同期バックグラウンド スレッド (`HashWorker`) は、インターフェイスをブロックせずに MD5 および SHA-256 暗号化ハッシュを計算します。 ディレクトリの場合は、ネストされたファイルとサブフォルダーの合計数をスキャンしてレポートします。

## 3. ユニバーサル リスター (`F3` / `Fn+F3` / `cm_View`)

Quick View はデュアルパネル ウィンドウ内での高速プレビュー用に最適化されていますが、**Universal Lister** (`F3` / `Fn+F3` / `cm_View`) は、専用のトップレベルの非モーダル ウィンドウ (`UniversalViewerDialog`) を開きます。 複数の Universal Lister ウィンドウを同時に開くことができるため、ドキュメントを並べて比較したり、セカンダリ ディスプレイでログをストリーミングし続けることができます。

### 上部のクイックアクションツールバー

Lister には、ビュー モード、ナビゲーション、および表示設定に迅速にアクセスできる統合されたクイック アクション ツールバーが備えられています。 

```
[Text (1)] [Hex (2)] [Wrap (Alt+W)] [Line Numbers (Alt+L)] [Tail (F5)] | [◀ Prev (P)] [Next ▶ (N)] | [🔍 Search (Ctrl+F)] [Go to Line (Ctrl+G)] | [Open in System (Ctrl+O)] [Fullscreen (F11)]
```


 - **テキスト モード (`1`) / 16 進モード (`2`)**: デコードされた文字の表示と生のバイト検査を瞬時に切り替えます。 
- **ワードラップ (`Alt+W` / `⌥W`)**: 長い行のソフトワードラップを切り替えます。 
- **行番号 (`Alt+L` / `⌥L`)**: 行番号のガターを切り替えます。 
- **テール モード (`F5`)**: 自動的にスクロールし、新しく書き込まれたログ データをリアルタイムでキャプチャします。 
- **前のファイル (`P`) / 次のファイル (`N`)**: ビューア ウィンドウを閉じずに、親フォルダーのファイル テーブル内の隣接するファイルに移動します。 
- **検索 (`Ctrl+F` / `Cmd+F`)**: ドッキングされた下部の検索バーを開きます。 
- **行に移動 (`Ctrl+G` / `Cmd+G`)**: ターゲット コードに直接ジャンプするための行番号の入力を求めます。 
- **システムで開く (`Ctrl+O` / `Cmd+O`)**: ファイルを macOS システムのデフォルト アプリケーション (プレビュー、Safari、Xcode など) に渡します。 
- **全画面 (`F11` / `Alt+Enter`)**: リスター ウィンドウを最大化してディスプレイ全体に表示します。

### 3.1 ドメイン 1: ドキュメントと構造化された書籍

ATBCmder には、構造化ドキュメント、スライドデッキ、電子ブック、書式設定されたテキスト用の特殊なレイアウト エンジンが組み込まれているため、外部のオフィス スイートの起動を待つ必要がなくなります。

#### 3.1.1 Word およびリッチ テキスト ドキュメント (`DocumentPanel`)

Microsoft Word (`.docx`、`.doc`)、リッチ テキスト (`.rtf`)、または OpenDocument (`.odt`) ファイルで `F3` を押すと、ATBCmder は `DocumentPanel` を実行します。 

- **ドキュメント ページ カード**: 構造化されたページを中央の紙カード (`.doc-page`) にレンダリングし、現代のワード プロセッサのレイアウトに一致する鮮明なタイポグラフィと余白を備えます。 
- **書式設定の保持**: 段落階層、太字/斜体/下線スタイル、フォントの色のバリエーション、順序なしリストと番号付きリスト、およびインライン ハイパーリンクを保持します。 
- **複雑なテーブルと埋め込み画像のレンダリング**: 境界線付きのセル間隔を持つ複雑な複数列のテーブル グリッドを解析し、埋め込まれたインライン ラスター イラストをレンダリングします。 
- **ページ ズームと検索**: 詳細なページ ズーム コントロール (`Ctrl++` / `Ctrl+-` またはズーム スピン ボックス) と統合された文書内検索バー (`ViewerSearchBar`)。

#### 3.1.2 プレゼンテーション スライドデッキ (`PresentationPanel`)

For Microsoft PowerPoint presentations (`.pptx`, `.ppt`), ATBCmder launches `PresentationPanel`:

 - **スライド カード リーダー**: 各スライドは抽出され、影付きの個別のプレゼンテーション カード (`.slide-card`) としてフォーマットされるため、コンテンツを順番に確認できます。 
- **スライド セレクター ストリップ**: ビジュアル ナビゲーション ドロワーには、サムネイル インデックス付きのすべてのスライドがリストされ、100 枚のスライド デッキ内の任意のスライドに即座にジャンプできます。 
- **スライド検索**: `Cmd+F` を押して、スライドのタイトル、箇条書き、スピーカー ノート、吹き出しテキスト ブロックをデッキ全体で検索します。

#### 3.1.3 PDF ドキュメント ビューア (`PdfPanel`)

`PySide6.QtPdf` および `QPdfView` をネイティブに利用する ATBCmder には、エンタープライズ グレードの PDF リーダーが組み込まれています。 

![PDF Viewer](images/pdf_viewer.png)
 *図 4.2: ブックマークの概要、ページのサムネイル ストリップ、文書内検索、および読書テーマを備えた統合 PDF ビューア。*

 - **連続複数ページ スクロール**: 複数ページ モード (`QPdfView.PageMode.MultiPage`) で数百ページにわたってシームレスにスクロールするか、1 ページおよび 2 ページの本の見開きビューに切り替えます。 
- **ドキュメントサイドバー**:
 - *概要/ブックマーク ツリー*: PDF 目次 (`QPdfBookmarkModel`) の章またはセクションの見出しをクリックすると、そのセクションに直接ジャンプします。 
- *ページ サムネイル ストリップ*: 垂直サムネイル リスト (`PdfThumbnailList`) を介して、レイアウトとグラフィック要素を視覚的にスキャンします。 
- **ドキュメント内の検索と強調表示**: `Cmd+F` を押してドキュメント全体のテキストを検索します。 リアルタイムの出現インデックス作成 (`Match 3 of 28`) により、一致したものが画面上で強調表示されます。 `Enter` または `Shift+Enter` を使用してオカレンス間をジャンプします。 
- **読書テーマ**:
 - *通常*: 標準的なドキュメント用紙のレンダリング。 
- *反転ナイトモード*: RGB ピクセルの輝度 (`InvertColorEffect`) を反転し、暗い環境でも目に負担をかけずに快適に読書できます。 
- *セピアの暖かさ*: 長時間にわたる文書レビュー中のブルーライトの放射を軽減する、柔らかい温かみのあるトーン。 
- **セキュリティと暗号化**: `PdfPasswordDialog` を介して暗号化された PDF ファイルのパスワードの入力をシームレスに要求し、`PdfPropertiesDialog` を介して作成者/プロデューサーのメタデータを検査します。

#### 3.1.4 EPUB 電子ブック (`EpubPanel`)

EPUB 形式 (`.epub`) での技術文書、マニュアル、またはデジタル ブックの管理は、ATBCmder にネイティブです。 

- **デュアルエンジン アーキテクチャ**: 最小限の環境では `QTextBrowser` への自動フォールバックを備えた高忠実度 Web エンジン レンダラー (豊富な CSS スタイルおよび SVG ベクター イラストレーション用の `QWebEngineView` と `EpubUrlSchemeHandler`) を採用します。 
- **目次サイドバー**: ネストされた章ツリー (`QTreeView`) を表示し、ワンクリックで本の章と付録の間を移動できます。 
- **タイポグラフィとフォントのスケーリング**: 下部のツールバーのフォント スライダーを使用して、読み上げテキストのサイズを動的に調整します。

### 3.2 ドメイン 2: データ、テーブル、開発者ランタイム

ATBCmder は、技術ユーザー、データ アナリスト、ソフトウェア エンジニア向けに、外部データベース クライアントやスプレッドシート アプリケーションのオーバーヘッドを排除する即時オフライン データ検査ツールを提供します。

#### 3.2.1 高性能スプレッドシート (`SpreadsheetPanel`)

負荷の高いオフィス スイートで大きな CSV ファイルや複数シートの Excel ワークブックを開くと、10 ～ 20 秒かかることがあります。 ATBCmder の `SpreadsheetPanel` はそれらを即座にレンダリングします。 

![Excel Spreadsheet and Data Preview](images/xls_viewer.png)
 *マルチシート タブと固定座標を備えた Universal Lister での高性能 Excel スプレッドシート プレビュー*

 - **形式のサポート**: Microsoft Excel (`.xlsx`、`.xls`)、カンマ区切り値 (`.csv`)、およびタブ区切り値 (`.tsv`)。 
- **マルチシート タブ**: 複数のシートを含むワークブックには下部のタブ バー (`QTabBar`) があり、データ シート間の素早い切り替えが可能になります。

- **固定された列ヘッダーと行ヘッダー**: 方向を明確にするために、標準のスプレッドシート座標 (`A, B, C...` および `1, 2, 3...`) はスクロール中に固定されたままになります。

- **高速検索**: `Cmd+F` を押して、リアルタイムのセル フォーカスですべての列のセルの内容を検索します。

#### 3.2.2 SQLite データベース ブラウザ (`SqlitePanel`)

外部 GUI クライアントを使用せずに SQLite データベース (`.sqlite`、`.sqlite3`、`.db`) を直接検査します。 

- **テーブルとビューのディレクトリ**: 左側のサイドバーには、すべてのデータベース テーブルとビューがアクティブな行数とともにリストされます。 いずれかのテーブルをクリックすると、その内容がすぐにロードされます。 
- **仮想化データ ビュー**: 高性能 `VirtualSpreadsheetModel` を使用して、大規模なテーブルをシームレスにスクロールします。 
- **Interactive SQL クエリ コンソール**: 上部のクエリ エディターにカスタム SQL クエリを入力し、**`Ctrl+Return`** (または `Cmd+Return`) を押して実行します。 結果はテーブル ビューに即座に取り込まれます。 
- **データ型の書式設定**: データを安全に処理します。バイナリ BLOB を `<BLOB: N B>` として書式設定し、空のフィールドを斜体の `NULL` として表示します。 
- **データのエクスポート**: 右クリックして、選択したレコードをコピーするか、クエリ結果を CSV または TSV にエクスポートします。

#### 3.2.3 Jupyter ノートブック (`NotebookPanel`)

データ サイエンスの実験、機械学習の実行、Python 分析ノートブック (`.ipynb`) を確認します。 

- **ゼロサーバー ネイティブ レンダリング**: アクティブな Jupyter または JupyterLab サーバー デーモンを必要とせずに、JSON ノートブック構造を完全にオフラインで解析します。 
- **カードベースのセル レイアウト**:
 - *マークダウン セル*: 見出し、太字のテキスト、リストを備えたきれいなタイポグラフィーにレンダリングされます。 
- *コードセル*: 構文強調表示された Python コード、行番号、セル実行バッジ (`[1]`、`[14]`) でフォーマットされます。 
- *出力ブロック*: コンソール出力ストリーム、エラー トレースバック、およびインライン Base64 エンコードされたチャートとグラフ (PNG/SVG) を表示します。

#### 3.2.4 コードとプレーンテキストの表示 (`TextPanel`)

主要なテキスト検査エンジンは、高速ブラウジングと膨大なデータ ダンプ向けに最適化されています。 

- **チャンク 64 KB ローダー (`FileLoaderWorker`)**: 自動改行境界スナップ機能を使用して、大きなファイルを 64 KB ブロックで読み取り、スレッドのフリーズや UTF-8 マルチバイト文字の破損を防ぎます。 
- **Pygments 構文ハイライト**: 動的なライト/ダーク モード適応により、150 を超えるプログラミングおよび構成言語がサポートされています。 
- **ダイナミック エンコーディング スイッチャー**: ステータス バーの UTF-8、GB18030、Big5、Shift-JIS、Windows-1252、および ISO-8859-1 間の手動切り替えによる統計的文字セット検出 (`chardet`)。 
- **ライブ テール モード (`F5`)**: `FileTailWatcher` を使用して、追加ログ行をリアルタイムでストリーミングし、UNIX `tail -f` と一致させます。 もう一度 `F5` を押して一時停止します。

#### 3.2.5 未加工の 16 進バイト検査 (`2` / 16 進モード)

バイナリ、ファームウェア ダンプ、コンパイルされたライブラリ、または破損したファイルを検査する場合:

 - **16 バイトの 16 進グリッド**: 8 桁の 16 進オフセット アドレス、2 つの 8 バイトのビジュアル列に分割された 16 の 16 進数バイト、および右側に印刷可能な ASCII テキスト (制御バイトの場合は `.`) を表示します。 
- **自動 16 進数検出**: ファイルの最初の 1 KB 内でヌル バイト (`\x00`) が検出された場合、ATBCmder は端末の文字化けを防ぐために自動的に 16 進数モードに切り替えます。

#### ウォーターマークモジュール

4 つのプリセット配置を使用して、プロフェッショナルなオーナーシップのブランディングを適用します。

- **スタンプ (`stamp`)**: 右下隅に配置される個別の認証スタンプ。 
- **バナー (`banner`)**: キャンバス全体に表示される水平方向の半透明のブランド バナー。 
- **単一ロゴ (`single`)**: 不透明度スライダーを使用して、自由に配置可能な単一ロゴまたはテキスト透かし。 

---

### 4.3 シームレスなラウンドトリップ VFS 編集 (リモートおよびアーカイブ)

ATBCmder のエディタ サブシステムの最も強力な点は、**ユニバーサル VFS 統合** です。 

- リモート SFTP サーバーに保存されているシェル スクリプト、AWS Nextcloud WebDAV マウント内の設定ファイル、またはネストされた `.zip` アーカイブ (`vfs://`) 内のスクリーンショットで `F4` を押すかどうか:
 1. ATBCmder は、ファイルを安全な一時サンドボックスに非同期的にダウンロードします。 
2. ファイルは `EditorWindow` または `ImageEditorDialog` で開きます。 
3. `Cmd+S` を押すと、ATBCmder は保存イベントをインターセプトし、変更されたファイルを同期し、更新されたデータを SFTP/SMB 経由で自動的にストリーミングして戻すか、`RepackWorker` を実行してアーカイブを再パックします。 
4. エディタを閉じると、一時キャッシュ ファイルがきれいにスクラブされます。 ファイルを手動で解凍、編集、再アップロードする必要はありません。

## 5. ⚡ プロのヒントと詳細

これらの高度な機能をマスターして、検査と編集の効率を最大限に高めます。

### プロのヒント 1: `F3` を使用した動的オーディオ キューの取り込み

音楽コレクションを参照しているときにオーディオ プレーヤーを **バックグラウンド再生モード** で実行している場合、さらに音楽をキューに入れるためにダイアログを再度開く必要はありません。 

1. いずれかのファイル パネルで 1 つ以上のオーディオ ファイルを強調表示します。 
2. **`F3`** (または `Fn+F3`) を押します。 
3. ATBCmder は、オーディオ プレーヤー インスタンスがすでにアクティブであることを検出し、現在再生中のトラックを中断することなく、実行中のプレイリスト (`append_tracks`) に自動的に**選択されたトラックを追加**します。

### プロのヒント 2: カスタム ファイルの関連付け (`cm_FileAssoc`)

デフォルトでは、`F3` を押すとユニバーサル リスターが開き、`F4` を押すと内部コード エディターが開きます。 ただし、**ファイル関連付けマネージャー** (`cm_FileAssoc`) を使用して、特定のファイル拡張子を外部デスクトップ アプリケーションまたはカスタム シェル コマンドにマップできます。 

**構成 ➔ ファイル関連付けの構成** に移動します。 

- 拡張機能 (`*.rs`、`*.py`、`*.psd` など) をカスタム アクションにマッピングできます。 
- **内部コマンド**: 内部コマンダーのアクションにバインドします (例: `cm_View`、`cm_Edit`)。 
- **トークン置換を使用した外部シェル コマンド**:
 - `%f` ➔ 絶対ファイル パスに置き換えられます (例: `/Users/brain/main.rs`)。 
- `%d` ➔ 親ディレクトリのパスに置き換えられます (例: `/Users/brain`)。 
- `%n` ➔ 拡張子なしのファイル名に置き換えられます (例: `main`)。 
- `%e` ➔ ドットなしのファイル拡張子に置き換えられます (例: `rs`)。 

*Rust ファイルの外部関連付けの例:*
 ```bash
code --goto %f
```

### プロのヒント 3: DevOps ログのライブ テール モード (`F5`)

ローカル サーバー デーモン、Docker コンテナ、またはビルド スクリプトをデバッグするときは、Universal Lister でログ ファイル (`F3`) を開き、**`F5`** を押します。 

- `FileTailWatcher` デーモンを使用します。 
- Lister は自動的に一番下までスクロールし、新しく追加された行をリアルタイムで画面にストリーミングし、UNIX `tail -f` の動作と一致します。 
- 発生したエラーを追跡しながら、検索フィルターをアクティブにしておくことができます。

### プロのヒント 4: マルチギガバイト ファイルの任意のオフセット ストリーミング

20 GB のデータベース ダンプまたはディスク イメージを検査する必要がある場合は、標準のエディターで開かないでください。 ATBCmder のユニバーサル リスターでは次のようになります。 

- **行に移動 (`Ctrl+G`)** またはジャンプ スライダー コントロールを使用します。 
- 基礎となる `FileLoaderWorker` は、直接バイナリ ファイル ポインター シーク (`fh.seek(offset)`) を使用し、ビューのレンダリングに必要な正確な 64 KB ブロックのみを読み取ります。 
- メモリ オーバーヘッドをゼロにしながら、数テラバイトのボリュームの任意のセクタを瞬時に検査できます。

## 6. ステップバイステップの実践的なレシピ

### レシピ 1: 機密性の高いスクリーンショットの検査と編集

**目標**: 機密 API トークンまたは顧客情報を含むスクリーンショットをキャプチャしたので、公開問題追跡ツールにアップロードする前にそれを編集する必要があります。 

```
Step 1: Highlight screenshot.png in the active panel and press F3 (Universal Lister).
Step 2: On the top toolbar, click "Edit Image" to launch the Image Editor.
Step 3: Select the "Mosaic / Blur" tool from the tool palette.
Step 4: Click and drag a selection rectangle over the API token to pixelate the text.
Step 5: Select the "Crop" tool, frame the relevant portion of the window, and press Enter.
Step 6: Click "Save" (Cmd+S) to overwrite, or "Save As" to create screenshot_redacted.png.
Step 7: Press Esc to close the editor; your clean image is ready in the file panel.
```

### レシピ 2: ライブログモニタリングと Hex フォレンジック検査

**目標**: バックグラウンド プロセスがエンコード エラーで失敗します。 ログをライブで監視し、不正な形式のシーケンス周辺の生のバイトを検査する必要があります。 

```
Step 1: Highlight server.log in the active panel and press F3.
Step 2: Press F5 to activate Tail Mode. Watch incoming live log entries stream past.
Step 3: When the error appears, press F5 again to pause tailing.
Step 4: Press Ctrl+F and search for the error code (e.g. "0xEF").
Step 5: Press 2 on your keyboard to switch into Hex Mode.
Step 6: Inspect the exact 16-byte hexadecimal dump to examine unprintable control characters.
Step 7: Press 1 to return to formatted text mode, or Esc to close.
```


 ---

### レシピ 3: 迅速なソース コード作成と Git ステージング

**目標**: 現在のプロジェクト リポジトリに新しいシェル スクリプトを作成し、標準の bash ヘッダーを設定し、ATBCmder を終了せずに実行できるように準備します。 

```
Step 1: In the active directory, press Shift+F4 (cm_EditNew).
Step 2: In the dialog prompt, type "build_release.sh" and press Enter.
Step 3: The Internal Code Editor opens immediately with an empty buffer.
Step 4: Type your script. Notice that auto-indent automatically indents loops and if-blocks:
        #!/usr/bin/env bash
        set -euo pipefail
        echo "Building binaries..."
Step 5: Press Cmd+S (⌘S) to save the file atomically to disk.
Step 6: Press Cmd+W (⌘W) to close the editor.
Step 7: With build_release.sh highlighted in the panel, press Alt+Enter (cm_SetFileProperties).
Step 8: Check the "Execute" permission for Owner (chmod +x) and press Enter.
```

## 7. 安全性とシステムの警告

> [!WARNING]
 > **外部変更ウォッチャー**
 > 内部エディタ (`F4`) での作業中に、開いているファイルが外部アプリケーションによって変更または切り捨てられると、ATBCmder は保存する前に外部変更の競合警告を表示します。 最新のディスク バージョンを検査するには常に [**再ロード**] を選択し、ローカルの変更を別のファイルに保存するには [**名前を付けて保存**] を選択してください。 

> [!IMPORTANT]
 > **バイナリ ファイルの安全性: テキスト モードと 16 進モード**
 > 不明なバイナリ ファイルをテキスト モードで開き、ディスクに保存し直すと、UTF-8 デコード置換によりファイルが永久に破損する可能性があります (`\ufffd`)。 ATBCmder の Universal Lister はデフォルトで読み取り専用なので、検査中にバイナリ ファイルが誤って上書きされることはありません。 

> [!CAUTION]
 > **リモート ネットワーク共有のパフォーマンスを簡単に表示**
 > クイック ビュー (`Cmd+Q`) がアクティブな状態で高遅延リモート サーバー (FTP、SFTP、または WebDAV) を参照している場合、大量のリモート ビデオまたはアーカイブ ファイルをプレビューすると、リモート ストリーミングがトリガーされます。 ネットワーク帯域幅が制限されている場合は、クイック ビューをオフ (`Cmd+Q`) に切り替えて、ディレクトリ ツリーをフルスピードで参照します。 

> [!TIP]
 > **macOS ファンクション キーのアクセシビリティ**
 > 最新の Apple MacBook および Magic Keyboard では、ファンクション キー (`F1`-`F12`) はデフォルトでハードウェア コントロール (明るさ、メディア再生) にマップされています。 `F3` または `F4` をトリガーするには、**`Fn`** キーを押し続けます (例: `Fn+F3`、`Fn+F4`)。 あるいは、macOS *システム設定 ➔ キーボード ➔ キーボード ショートカット ➔ ファンクション キー* で **「F1、F2 などのキーを標準のファンクション キーとして使用する」** を有効にします。

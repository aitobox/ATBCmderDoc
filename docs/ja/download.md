# 第10章：ダウンロードとインストール

ATBCmder にご興味をお持ちいただきありがとうございます。 お客様のニーズに合わせて、2 つの異なるダウンロード方法とインストール方法を提供しています。 

> [!IMPORTANT]
 > **システムとアーキテクチャの要件**
 >
 > - **オペレーティング システム**: macOS 12.0 (Monterey) 以降 (macOS 13 Ventura、macOS 14 Sonoma、macOS 15 Sequoia を含む)。 
> - **サポートされているハードウェア アーキテクチャ**: **Apple Silicon (M1 / M2 / M3 / M4、ARM64)**。 
> - **Intel (x86_64) 互換性**: 現時点では、Intel ベースの Mac は **サポートされていません**。

## 1. Mac App Store (推奨)

これは、ATBCmder をインストールするための推奨される方法です。 **ATBCmder が Mac App Store で正式に入手可能になりました!** 公式 Mac App Store からダウンロードすると、シームレスな自動更新、ネイティブ macOS サンドボックス保護、および最適なシステム統合が確実に得られます。 

- **Mac App Store**: [Mac App Store で ATBCmder をダウンロード](https://apps.apple.com/app/atbcmder/id6792398333)

## 2.DMG インストーラーのダウンロード

Mac App Store にアクセスできない場合、または直接ダウンロードしたい場合は、Apple Silicon (ARM64) 用にネイティブに構築されたスタンドアロンの DMG インストーラー パッケージが提供されます。 

- **DMG ダウンロード リンク**: [ATBCmder DMG をダウンロードするにはここをクリック](https://storage.aitobox.com/@s/bNAshV6G/ATBCmder) *(Apple Silicon / ARM64 のみ)*

 *注意: DMG 経由でインストールする場合、macOS のセキュリティ機能により、アプリケーションを初めて開くときに、[システム設定 > プライバシーとセキュリティ] でアプリケーションを明示的に許可する必要がある場合があります。 Intel (x86_64) Mac はサポートされていません。*

### ⚠️ フルディスクアクセスを許可する

ATBCmder はファイル管理ツールであり、ユーザーからの明示的なディスク管理権限が必要です。 次の手順に従ってください。 

1. 画面の左上隅にある Apple アイコンをクリックし、**システム設定** (古い macOS バージョンでは「システム環境設定」) を選択します。 
2. 左側または右側のメニューで [**プライバシーとセキュリティ**] に移動します。 
3. 下にスクロールして、**フルディスクアクセス**を選択します。 
4. リストでアプリケーション (**ATBCmder**) を見つけ、スイッチを切り替えてオンにします。 アプリケーションがリストにない場合は、下部にある **+** ボタンをクリックして手動で追加します。 
5. システムは、Mac ログイン パスワードを入力するか、Touch ID を使用して変更を確認するように求めます。

## デュアルパネルの哲学

macOS Finder のような従来の単一ウィンドウのデスクトップ ファイル マネージャーでは、ユーザーは重複するウィンドウを開いて、ソース フォルダーと宛先フォルダーを追跡できなくなり、誤って間違ったサブフォルダーにドロップする危険性が生じるという終わりのないサイクルを強いられます。 

```
従来の単一ウィンドウ操作 (Finder):
┌────────────────────────┐      ┌────────────────────────┐
│ フォルダ A (どこだっけ?)│ ──?  │ フォルダ B (どれだ?)   │  → ウィンドウが重なり乱雑、
└────────────────────────┘      └────────────────────────┘    誤ドロップの危険

ATBCmder の流儀 (正統派デュアルパネル):
┌───────────────────────────────┬───────────────────────────────┐
│   アクティブパネル (操作元)   │ 非アクティブパネル (操作先)   │
│  操作を待つファイル一覧       │  迷いのない確実な転送先       │
│  [ コピー / 移動 / 比較 / 同期 ════════════════════════════► ]│
└───────────────────────────────┴───────────────────────────────┘
```


 ATBCmder は、**ソース-ターゲット デュアルパネル パラダイム** を通じてこれを解決します。 

- **常に迷わない操作視界**: 2 つの独立したディレクトリ ビューが常に並べて表示されます。 
- **予測可能な方向操作**: コピー (`F5`) または移動 (`F6`) をトリガーすると、ATBCmder はアイテムを **アクティブ パネル** (カーソルがある場所) から **非アクティブ パネル** (反対側のビュー) に自動的に転送します。 ドラッグしたり、推測したり、隠れた目的のウィンドウを探したりする必要はありません。 
- **指先が跳ねるようなキーボード操作**: 手をキーボードの上に置いてください。 ディレクトリを移動し、ワイルドカードを使用してファイルを選択し、アーカイブを検査し、ミリ秒単位でバッチ変換を実行します。 
- **Finder ウィンドウの煩雑さゼロ**: ローカル ボリューム、ネットワーク サーバー (FTP、SFTP、SMB、WebDAV)、アーカイブ コンテンツ (`.zip`、`.7z`、`.tar`)、およびバックグラウンド転送キューなど、すべてを 1 つのウィンドウで処理します。

### UI ランドマークのリファレンス

1. **メニュー バーとネイティブ macOS の統合 (`[1]`)**: 完全な macOS アプリケーション メニューのサポート、標準ショートカット (`⌘,`、`⌘Q`、`⌘W`)、およびすべての内部 Commander コマンドへのフル メニュー アクセス (`cm_*`)。 
2. **メイン ツールバーと高速ランチャー (`[2]`)**: 検索 (`Alt+F7`)、バックグラウンド転送キュー (`cm_OperationsPanel`)、環境設定 (`Cmd+,`)、およびドライブ セレクターにワンクリックですぐにアクセスできます。 
3. **対話型ブレッドクラム パス バー (`[3]`)**: パス内の任意のディレクトリ セグメントをクリックすると、階層を直接上にジャンプします。 セグメントのドロップダウン矢印をクリックしてサブディレクトリを参照します。 
4. **フォルダー タブとワークスペース (`[4]`)**: 各パネルで無制限のタブを開き (`Cmd+T`)、タブを閉じ (`Cmd+W`)、お気に入りの場所をロックし、デュアル パネル タブ ワークスペース全体を保存します (`cm_SaveFavoriteTabs`)。 
5. **デュアル ファイル パネル (`[5]`)**: 独立したファイル テーブル。 アクティブなパネルには、明確なアクセントの境界線とフォーカスされたカーソルが表示されます。 `Tab` を使用してフォーカスを即座に切り替えます。 
6. **中央のツールバーとドラッグ可能なスプリッター (`[6]`)**: パネル分割器に直接配置された垂直のクイックアクション ストリップ。 表示 (`F3`)、編集 (`F4`)、コピー (`F5`)、移動 (`F6`)、新規フォルダー (`F7`)、削除 (`F8`)、ワイプ、 およびパネルの交換 (`cm_Exchange`)。 スプリッターを左右にドラッグしてパネルのサイズを変更します。 
7. **ステータス バーとドライブ ストレージ メーター (`[7]`)**: ライブ ファイル数、選択したアイテムの統計、総バイト サイズ、および空き領域の計算を含むアクティブ ボリューム ストレージ容量ゲージを表示します。

## 自分の道を選択してください

これまでデュアルパネル ツールに触れたことがない人でも、Total Commander を 20 年間使用してきた人でも、ATBCmder は最適化されたパスを提供します。

### 🟢 トラック A: デュアルパネル ファイル マネージャーは初めてですか?

*macOS でファイルを管理するための、より高速でクリーンな方法へようこそ。*

 Finder または標準のデスクトップ オペレーティング システムを使用している場合、通常のファイル マネージャーは最初は見慣れないように見えるかもしれません。 核となるパターンを一度学べば、散在するウィンドウ間でファイルをドラッグする作業にはもう戻りたくないでしょう。 

1. **中心的な概念から始めます**: [第 1 章: 基本と macOS のセットアップ](getting_started.md) を読んで、アクティブパネルと非アクティブパネル、中央のツールバー、macOS ディスク権限の付与について理解してください。 
2. **日常的な操作をマスターする**: [第 3 章: 日常的なファイル操作とキュー](file_operations.md) で、マウスに触れずにコピー、移動、名前変更、削除する方法を学びます。 
3. **すべてを即座にプレビュー**: [第 4 章: ユニバーサル リスターとエディタ](viewers_and_editors.md) で、1 回のキーストロークで画像をプレビューし、オーディオ ファイルを聴き、コードを読み取り、PDF を検査する方法を説明します。 
4. **実践ガイドに従ってください**: [第 9 章: 実際のレシピとトラブルシューティング](faq_howtos.md) で実践的な日常のワークフローとよくある質問を確認してください。 

---

### ⚡ トラック B: Total Commander / Double Commanderからの移行?

*ご存知のパワーとキーボードの反射機能はすべて、macOS 用にネイティブに設計されています。*

 ATBCmder は、不格好な X11、ワイン ラッパー、メンテナンスされていないレガシー ポートを実行せずに、本物の Commander エクスペリエンスを最新の macOS に提供するために作成されました。 

1. **デュアル マトリックス キーバインドをマスターする**: [第 8 章: マスター キーボード ショートカット](keyboard_shortcuts.md) の完全な並列ショートカット マトリックス (`macOS Cmd` と `Commander Fn`) を確認してください。 
2. **高度なパワー ツールを利用する**: [第 5 章: パワー ツールとオートメーション] (power_tools.md) のバッチ マルチ名前変更ツール (`Ctrl+M`)、サイドバイサイド ファイル差分 (`Meta+Shift+F12`)、フォルダー同期 (`Shift+F12`)、および高度な検索を使用します。 
3. **リモートおよび仮想システムへの接続**: ライブ再パックを使用して `.zip` および `.tar` アーカイブ内を直接参照および編集するか、[第 6 章: 仮想ファイル システムとネットワーク](network_and_vfs.md) で SFTP、SMB、および WebDAV 経由でリモート サーバーを管理します。 
4. **セットアップのカスタマイズと移植**: [第 7 章: 設定とカスタマイズ](preferences_and_customization.md) で、コマンドを再バインドし、自動更新動作を構成し、構成 XML をエクスポートします。

## マスター目次

完全な ATBCmder ドキュメント スイートを参照してください。

### 🚀 [第 1 章: 基本と macOS のセットアップ](getting_started.md)

デュアルパネルの哲学を理解し、インターフェイスの構造を調べ、オンボーディング アシスタント (`cm_GrantFilesystemAccess`) を介して macOS App Sandbox の権限を構成し、30 以上のロケールにわたってシステム言語のオーバーライドを設定し、ライト/ダーク テーマを調整します。

### 🧭 [第 2 章: ナビゲーションとフォルダー タブ](navigation_and_tabs.md)

インタラクティブなブレッドクラム、キーボード ジャンプ (`Ctrl+\`、`Backspace`)、マルチタブ構成 (`Cmd+T`、`Cmd+W`)、デュアルパネルのお気に入りワークスペース セット (`cm_SaveFavoriteTabs`)、ディレクトリ ホットリスト ブックマークを使用して、ディレクトリ ツリー内を簡単に移動できます。 (`Ctrl+D`)、および柔軟な表示モード (要約、全列、サムネイル、ツリー ビュー、およびフラット ブランチ ビュー `Cmd+B`)。

### 📁 [第 3 章: 毎日のファイル操作とキュー](file_operations.md)

高速で堅牢なファイル操作を実行します: コピー (`F5`)、移動 (`F6`)、新規フォルダー (`F7`)、ゴミ箱への削除 (`F8`)、およびインラインのクイック名前変更 (`F2`)。 マスター ワイルドカードと属性の選択、ドラッグ アンド ドロップの相互運用性、衝突競合の解決、UNIX 8 進数のアクセス許可 (`Alt+Enter`)、およびバックグラウンド オペレーション キュー (`cm_OperationsPanel`) を介した非同期転送の監視。

### 👁️ [第 4 章: ユニバーサル リスターと組み込みエディター](viewers_and_editors.md)

重いサードパーティ ソフトウェアを起動せずにファイルを検査します。 ライブサイドパネルプレビューにはクイックビュー (`Ctrl+Q` / `Cmd+Q`) を使用し、Word ドキュメント、スプレッドシート、SQLite データベース、Jupyter ノートブック、EPUB、構文強調表示されたコード、生の 16 進バイト検査 (`2`) にはユニバーサル リスター (`F3`) を使用します。 画像の注釈と透かし (`F4`)、PDF ドキュメント リーダー、およびバックグラウンド オーディオ再生を備えた統合オーディオ/ビデオ メディア プレーヤー。 組み込みのテキスト エディタ (`F4`) を使用してファイルを直接編集します。

### ⚡ [第 5 章: パワーツールとオートメーション](power_tools.md)

複雑なファイル管理の課題を自動化: トークンと RegEx 置換によるバッチ複数名前変更 (`Ctrl+M`)、並列ビジュアル ファイル差分 (`Meta+Shift+F12`)、双方向ディレクトリ同期 (`Shift+F12`)、「フィード」による高度なマルチフィルター検索 (`Alt+F7`) to Listbox」、スポットライトと自然言語セマンティック コマンド (`/`)、ファイル スプリッターとリンカー、チェックサム検証 (MD5、SHA-256、CRC32)、安全なマルチパス ワイプ (`cm_Wipe`)、および組み込みターミナル (`Ctrl+J`)。

### 🌐 [第 6 章: 仮想ファイル システムとネットワーク](network_and_vfs.md)

統一された `vfs://` URI を使用して、リモート サーバーと圧縮アーカイブを通常のローカル フォルダーと同様に扱います。 `.zip`、`.tar`、`.7z` アーカイブ内を解凍せずに移動し、自動ライブ再パックでファイルをその場で編集し、暗号化されたアーカイブ (`Alt+F5`) を作成し、FTP、SFTP (SSH キー)、WebDAV、SMB/Samba にわたる永続的な接続を管理します。 ネットワーク共有。

### ⚙️ [第 7 章: 設定とカスタマイズ](preferences_and_customization.md)

ATBCmder を自分の作業スタイルに合わせて構成します。 リアルタイム競合警告によるプライマリ/セカンダリ ホットキーの検索とバインド、ファイル テーブル列と自動調整ルールのカスタマイズ、ファイル ウォッチャーの自動更新感度の調整、カスタム ファイル拡張子の関連付けの定義、ポータブル構成プロファイルのエクスポート/インポート (`cm_ExportConfiguration`)。

### ⌨️ [第 8 章: キーボード ショートカットをマスターする](keyboard_shortcuts.md)

ネイティブ macOS ショートカット (`Cmd` 修飾子) と従来の Commander ファンクション キー (`F1`-`F12`) を比較する、包括的なデュアル マトリックス ショートカット リファレンス ガイド。 Apple キーボードの `Fn` 修飾子の動作と macOS の「標準ファンクション キー」設定に関する専用の手順が含まれています。

### ❓ [第 9 章: 現実世界のレシピとトラブルシューティング](faq_howtos.md)

一般的な現実のタスクに関する実践的なステップバイステップのウォークスルー: ディレクトリのバックアップの同期、タイムスタンプを使用したカメラ写真ライブラリの名前の一括変更、ネットワーク NAS ドライブのマウント、リモート アーカイブ内の構成ファイルの更新、macOS サンドボックスのアクセス許可エラーや自動更新の問題の診断。

### 📥 [第 10 章: ダウンロードとインストール](download.md)

macOS 12.0 以降のモントレーからセコイアまでのインストール オプション。 Mac App Store から直接ダウンロードするか、Apple Silicon (M1/M2/M3/M4、ARM64 アーキテクチャ) 用にネイティブに構築されたスタンドアロンの DMG インストーラー パッケージを入手します。 *注意: Intel (x86_64) Mac は現在サポートされていません。*

# 개인정보 처리방침

**최종 업데이트:** 2026년 7월 20일 

ATBCmder는 귀하의 개인정보 보호를 최우선으로 하여 제작되었습니다. 우리는 귀하의 파일, 데이터 및 사용 습관이 전적으로 귀하의 것이며 전적으로 귀하의 통제하에 있어야 한다고 믿습니다.

## 데이터 수집

**우리는 개인 정보나 사용자 데이터를 수집, 저장, 공유 또는 전송하지 않습니다.** 

ATBCMder는 macOS 장치에서 완전히 로컬로 작동합니다. 

- 당사 서버에 "집으로 전화"를 걸지 않습니다. 
- 타사 분석 추적기, 원격 측정 또는 충돌 보고 기능은 포함되지 않습니다. 
- 파일 메타데이터, 검색 습관 또는 개인 정보를 수집, 검사 또는 분석하지 않습니다.

## 네트워크 액세스

ATBCmder에서 만든 모든 네트워크 연결(예: FTP, SFTP, WebDAV 또는 Samba 연결)은 장치와 명시적으로 구성한 원격 서버 간에 직접 설정됩니다. 당사는 이러한 연결이나 이를 통해 전송되는 데이터를 프록시, 가로채기, 모니터링하거나 액세스하지 않습니다.

## 앱 스토어 지침

이 정책은 Apple App Store 지침에 따라 당사의 데이터 관행을 명확히 하기 위해 제공됩니다. 우리는 사용자로부터 데이터를 전혀 수집하지 않기 때문에 공유, 판매 또는 삭제할 데이터가 없습니다.

# 제8장: 마스터 키보드 단축키 레퍼런스

ATBCMder는 처음부터 키보드 우선 파일 관리자로 설계되었습니다. 모든 파일 작업, 디렉터리 점프, 보기 변환 및 배치 유틸리티를 마우스 상호 작용 없이 실행할 수 있습니다. 

정통 Commander 전통과 기본 Apple 인체 공학을 연결하기 위해 ATBCmder는 **이중 매트릭스 키보드 아키텍처**를 사용합니다. 모든 명령은 클래식 Commander 기능 키(`F1`–`F12`, `Insert`, 숫자 키패드) 또는 기본 macOS 수정 코드를 사용하여 호출할 수 있습니다. (`⌘` 명령, `⌥` 옵션, `⇧` Shift, `⌃` 제어). 

---

## 1. 듀얼 매트릭스 철학 및 키 표기법

Total Commander 및 Norton Commander의 20년 머슬 메모리를 보유하고 있거나 기본 macOS Finder 바로가기 내에서 전적으로 살고 있는 경우에도 ATBCmder는 수동으로 다시 매핑할 필요 없이 기본적으로 반사 신경을 수용합니다. 

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      DUAL-MATRIX KEYBOARD ENGINE                            │
├──────────────────────────────────────┬──────────────────────────────────────┤
│  CLASSIC COMMANDER PARADIGM          │  NATIVE macOS PARADIGM               │
│  • Function Key Centric (F1–F12)     │  • Modifier Chords (⌘, ⌥, ⇧, ⌃)      │
│  • Dedicated Keypad Marking (+, -, *)│  • Finder Parity (⌘C, ⌘V, ⌘⌫, ⏎)     │
│  • Zero-Modal Terminal Velocity      │  • Native Menu Bar Integration       │
│  Examples:                           │  Examples:                           │
│    F5        ➔ Copy Files            │    ⌘C ➔ ⌘V   ➔ Copy Files            │
│    F6        ➔ Move Files            │    ⌘C ➔ ⌥⌘V  ➔ Move Files            │
│    Shift+F4  ➔ Create Text File      │    ⇧⌘4       ➔ Create Text File      │
│    Alt+F7    ➔ Find Files            │    ⌥⌘F       ➔ Find Files            │
└──────────────────────────────────────┴──────────────────────────────────────┘
```

### Apple 키보드 수정자 기호

이 가이드 전체와 ATBCmder의 기본 설정 대화 상자 내에서 키 조합은 표준 macOS 인쇄 문자를 사용하여 표시됩니다. 

| 문양 | 수정자 이름 | Windows/PC 해당 | 설명 | 
| :---: | :--- | :--- | :--- | 
| **`⌘`** | **명령** (`Cmd`) | `Win` / `Ctrl` | 기본 macOS 작업 수정자 키. | 
| **`⌥`** | **옵션** (`Alt`) | `Alt` | 대체 작업 및 특수 문자에 대한 보조 수정자입니다. | 
| **`⇧`** | **교대** | `Shift` | 선택 항목을 확장하고, 작업을 반전시키거나, 자본 모드를 활성화합니다. | 
| **`⌃`** | **제어** (`Ctrl`) | `Ctrl` | 터미널 제어 및 클래식 커맨더 코드 수정자. | 
| **`⎋`** | **탈출** (`Esc`) | `Esc` | 작업을 취소하거나, 필터를 지우거나, 대화 상자를 닫습니다. | 
| **`⏎`** | **반품** (`Enter`) | `Enter` | 작업을 실행하거나, 항목을 열거나, 대화 상자 프롬프트를 커밋합니다. | 
| **`⌫`** | **삭제/백스페이스** | `Backspace` | 뒤로 문자 삭제 또는 상위 디렉터리 탐색. | 
| **`⌦`** | **앞으로 삭제** | `Del` | 문자를 앞으로 삭제하거나 선택한 파일을 삭제합니다. | 
| **`⇥`** | **탭** | `Tab` | 소스 패널과 대상 패널 간에 초점을 교대로 전환합니다. | 
| **`⇞`** | **페이지 업** | `PgUp` | 하나의 창 뷰포트만큼 패널 목록을 스크롤합니다. | 
| **`⇟`** | **페이지 아래로** | `PgDn` | 패널 목록을 하나의 창 뷰포트 아래로 스크롤합니다. |

## 2. macOS 기능(`Fn`) 주요 지침

> [!IMPORTANT] 
> ### Mac 키보드에서 기능 키를 사용하는 방법 
> 
> 기본적으로 Apple 키보드(내장 MacBook 키보드, Magic Keyboard 및 Touch Bar Mac 포함)는 디스플레이 밝기, Mission Control, Spotlight, 받아쓰기, 미디어 재생 및 스피커 볼륨과 같은 하드웨어 제어에 최상위 물리적 행(`F1` ~ `F12`)을 할당합니다. 
> 
> 클래식 Commander 작업 흐름은 `F1`–`F12`에 크게 의존하기 때문에 두 가지 옵션이 있습니다. 
> 
> #### 방법 A: `Fn` 키 코드 유지(기본 기본 제공) 
> Mac 키보드의 왼쪽 하단에 있는 실제 **`Fn`** 키(또는 지구본 🌐 키)를 누른 상태에서 아무 기능 키나 누르세요. 
> 
> * **`Fn + F3`**: Lister에서 파일 보기 
> * **`Fn + F4`**: 파일 편집 
> * **`Fn + F5`**: 대상 패널에 파일 복사 
> * **`Fn + F6`**: 대상 패널로 파일 이동 
> * **`Fn + F7`**: 새 디렉터리 생성 
> * **`Fn + F8`**: 파일 삭제 
> * **`Fn + Shift + F4`**: 새 텍스트 파일 생성 및 편집 
> * **`Fn + Alt + F7`**: 파일 검색 열기 
> 
> #### 방법 B: macOS 설정에서 "표준 기능 키" 활성화(권장) 
> ATBCmder를 정기적으로 사용하는 경우 `F1`–`F12`을 누르면 기능 명령이 직접 트리거되고 `Fn`을 누르면 밝기 및 볼륨 조정이 트리거되도록 기능 행을 전환합니다. 
> 
> 1. **macOS 13 Ventura, macOS 14 Sonoma, macOS 15 Sequoia**: 
> - ** Apple 메뉴 ➔ 시스템 설정...**을 엽니다. 
> - 왼쪽 사이드바에서 **키보드**를 선택합니다. 
> - **키보드 단축키...** 버튼을 클릭하세요. 
> - 대화 상자 사이드바에서 **기능 키**를 선택합니다. 
> - **"F1, F2 등의 키를 표준 기능 키로 사용"**을 **ON**으로 전환합니다. 
> - **완료**를 클릭합니다. 
> 
> 2. **macOS 12 Monterey 및 macOS 11 Big Sur**: 
> - ** Apple 메뉴 ➔ 시스템 환경설정... ➔ 키보드**를 엽니다. 
> - **키보드** 탭에서 **"F1, F2 등의 키를 표준 기능 키로 사용"** 확인란을 선택합니다. 
> 
> #### Touch Bar가 장착된 MacBook Pro 모델 
> 
> * 왼쪽 하단의 물리적 **`Fn`** 키를 누르면 Touch Bar에 가상 `F1`–`F12` 행이 즉시 표시됩니다. 
> * 또는 **시스템 설정 ➔ 키보드 ➔ 터치 바 설정...**을 구성하고 ATBCmder가 활성 전면 애플리케이션인 경우 **"터치 바 표시"**를 **"F1, F2 등 키"**로 설정합니다. 
> 
> #### 전용 기능 행이 없는 컴팩트 키보드 
> 
> * 전용 `F` 키가 없는 60% 또는 65% 기계식 키보드를 사용하는 경우 손가락이 뒤틀릴 필요가 없습니다. 100% 작동 패리티를 제공하는 ATBCmder의 기본 macOS 수정자 코드(`⌘C`, `⌥⌘V`, `⇧⌘N`, `⌘⌫`, `⌥⏎`)를 사용하세요.

## 3. 컨텍스트 범위 바로가기 아키텍처

서로 다른 응용 프로그램 영역 간의 단축키 충돌을 방지하기 위해(예: 기본 파일 목록 내부 검색과 텍스트 파일 뷰어 내부 검색) ATBCmder는 모든 단축키를 고유한 계층적 컨텍스트로 분할합니다. 

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          APPLICATION SCOPE: Main                            │
│  Global commands, panel navigation, window management, toolbar, power tools │
├───────────────────────────────┬─────────────────────────────────────────────┤
│  PANEL SCOPE: FilePanel       │  MODAL TOOLS SCOPES                         │
│  Active during directory      │  • Viewer      (Lister preview window)      │
│  table and thumbnail browsing │  • Editor      (Built-in code editor)       │
│  (marking, range selection,   │  • Differ      (Side-by-side diff viewer)   │
│  inline editing, space count) │  • FindFiles   (Multi-threaded file search) │
│                               │  • MultiRename (Batch rename engine)        │
└───────────────────────────────┴─────────────────────────────────────────────┘
```
 

키 코드를 누르면 **`HotkeyManager`** 엔진: 

1. 활성 초점 컨텍스트(예: `Viewer` 또는 `FilePanel`)를 평가합니다. 
2. 정확한 바인딩이 일치하면 연관된 `cm_*` 명령이 즉시 실행됩니다. 
3. 로컬 컨텍스트에 바인딩이 없으면 키 입력은 `Main` 컨텍스트로 정상적으로 대체됩니다. 
4. 여전히 바인딩되지 않은 경우 표준 텍스트 편집 또는 시스템 키 입력 처리가 대신됩니다.

## 4. 마스터 분류 이중 매트릭스 테이블

다음 참조 표에는 ATBCmder에서 지원하는 모든 명령이 기능적 작업 흐름별로 분류되어 문서화되어 있습니다.

### 4.1 파일 작업

파일 작업은 일상 업무의 중추를 형성합니다. 모든 작업의 ​​기본값은 **소스 ➔ 대상** 패러다임입니다. 활성 패널에서 선택한 항목은 비활성 반대 패널에 열려 있는 디렉터리로 처리됩니다.

| 명령 ID | 설명 | 기본 macOS 단축키(⌘/⌥/⇧/⌃ 문자 포함) | 클래식 Commander 단축키(Fn 키 포함) | 컨텍스트 | 
| :--- | :--- | :---: | :---: | :---: | 
| `cm_View` | Universal Lister를 사용하여 파일 보기(읽기 전용 미리보기) | `⌘3` / `Space` *(훑어보기)* | `F3` / `Shift+F3` | 메인 | 
| `cm_Edit` | 내장된 텍스트 편집기에서 파일 열기 | `⌘4` | `F4` | 메인 | 
| `cm_EditNew` | 새 텍스트 파일을 생성하고 즉시 편집 | `⇧⌘4` / `⇧F4` | `Shift+F4` | 메인 | 
| `cm_Copy` | 선택한 파일을 활성 패널에서 대상 패널로 복사 | `⌘C` *(클립보드로)* / `F5` | `F5` | 메인 | 
| `cm_CopySamePanel` | 동일한 디렉터리 내에서 선택한 파일 복제/복제 | `⇧F5` | `Shift+F5` | 메인 | 
| `cm_Move` | 선택한 파일을 활성 패널에서 대상 패널로 이동 | `⌥⌘V` *(이동 붙여넣기)* / `F6` | `F6` | 메인 | 
| `cm_RenameOnly` | 커서 아래에 있는 파일의 빠른 인라인 이름 바꾸기 | `⏎` *(반품)* / `F2` | `F2` / `Shift+F6` | 메인 | 
| `cm_Rename` | 대화 상자를 통해 선택한 파일 이름 바꾸기 | `⇧F6` | `Shift+F6` | 메인 | 
| `cm_MkDir` | 새 디렉터리/폴더 만들기 | `⇧⌘N` / `F7` | `F7` | 메인 | 
| `cm_Delete` | 선택한 항목을 macOS 휴지통으로 삭제 | `⌘⌫` *(Cmd+삭제)* / `⌦` | `F8` / `Delete` | 메인 | 
| `cm_Wipe` | 파일을 안전하게 삭제(휴지통을 영구적으로 우회) | `⌥⇧⌫` / `⌥⌦` | `Alt+Delete` / `Shift+Delete` | 파일패널 | 
| `cm_Open` | 기본 앱으로 파일 열기 또는 디렉터리 입력 | `⌘↓` / `⏎` *(반품)* | `Enter` | 메인 | 
| `cm_SetFileProperties` | 파일 메타데이터, 날짜 및 UNIX 권한 검사 및 편집 | `⌥⏎` *(옵션+반품)* / `⌘I` | `Alt+Enter` | 메인 | 
| `cm_CountDirContent` | 커서 아래 디렉토리의 바이트 크기 계산 | `⌥⇧⏎` *(Option+Shift+Return)* | `Alt+Shift+Enter` | 파일패널 | 
| `cm_CalculateSpace` | 선택한 모든 디렉터리의 전체 크기 계산 | `⌃L` / `⌘L` | `Ctrl+L` | 메인 | 
| `cm_SymLink` | 대상 패널에 심볼릭 링크 생성 | `⌥⌘S` | *(메뉴: 파일 ➔ Symlink)* | 메인 | 
| `cm_HardLink` | 대상 패널에 파일 시스템 하드 링크 생성 | `⌥⌘H` | *(메뉴: 파일 ➔ 하드링크)* | 메인 | 
| `cm_PackFiles` | 선택한 파일을 아카이브로 압축/압축합니다(`.zip`, `.tar`, `.7z`) | `⌥F5` / `⌥⌘P` | `Alt+F5` | 메인 | 
| `cm_ExtractFiles` | 아카이브 내용을 대상 패널로 직접 추출 | `⌥F9` / `⌥⌘E` | `Alt+F9` | 메인 | 
| `cm_ArchiveView` | 가상 파일 시스템 디렉터리로 아카이브 입력(`vfs://`) | `⌃⇟` *(Ctrl+PgDn)* / `⌘↓` | `Ctrl+PgDn` | 메인 | 
| `cm_CompareContents` | 선택한 두 파일의 내용 비교 | `⇧F3` | `Shift+F3` | 메인 |

### 4.2 선택 및 표시

정통 파일 관리자는 신속한 다중 파일 선택에 탁월합니다. ATBCmder를 사용하면 마우스를 사용하지 않고도 개별 항목, 와일드카드 패턴, 확장 그룹 또는 연속 블록을 선택할 수 있습니다.

| 명령 ID | 설명 | 기본 macOS 단축키(⌘/⌥/⇧/⌃ 문자 포함) | 클래식 Commander 단축키(Fn 키 포함) | 컨텍스트 | 
| :--- | :--- | :---: | :---: | :---: | 
| `cm_MarkMarkAll` | 활성 패널의 모든 파일 및 폴더 선택 | `⌘A` | `Ctrl+A` / `Ctrl+Num+` | 메인 | 
| `cm_MarkUnmarkAll` | 활성 패널의 모든 파일 및 폴더 선택 취소 | `⇧⌘A` | `Ctrl+Shift+A` / `Ctrl+Num-` | 메인 | 
| `cm_MarkInvert` | 활성 패널에서 현재 선택 상태 반전 | `⌘I` / `⌃I` | `Num*` *(키패드 `*`)* | 파일패널 | 
| `cm_MarkPlus` | 와일드카드 패턴과 일치하는 그룹 선택(예: `*.ts`) | `⌘+` / `⌃+` | `Num+` *(키패드 `+`)* | 파일패널 | 
| `cm_MarkMinus` | 와일드카드 패턴(예: `*.log`)과 일치하는 그룹 선택 취소 | `⌘-` / `⌃-` | `Num-` *(키패드 `-`)* | 파일패널 | 
| `cm_MarkCurrentExtension` | 모든 파일 공유 커서의 파일 확장자 선택 | `⇧⌘E` / `⌥F8` | `Shift+Num+` / `Alt+Num+` | 메인 | 
| `cm_UnmarkCurrentExt` | 커서의 파일 확장자를 공유하는 모든 파일 선택 취소 | `⌥⇧Num-` | `Shift+Num-` / `Alt+Num-` | 메인 | 
| `cm_MarkCurrentName` | 커서의 기본 파일 이름을 공유하는 모든 파일 선택 | `⌥⌘N` | *(메뉴: 표시 ➔ 동일명)* | 메인 | 
| `cm_SelectOrDeselectFile` | 항목 선택을 전환하고 커서를 아래로 전진 | `Space` | `Insert` / `Space` | 파일패널 | 
| `Shift+Up / Shift+Down` | 연속 선택 범위 확대 또는 축소 | `⇧↑` / `⇧↓` | `Shift+↑` / `Shift+↓` | 파일패널 | 
| `Shift+PageUp / Shift+PageDown` | 전체 뷰포트 페이지로 연속 선택 확장 | `⇧⇞` / `⇧⇟` | `Shift+PgUp` / `Shift+PgDn` | 파일패널 |

내장된 텍스트 편집기인 Universal Lister, 병렬 차이 또는 일괄 대화 상자와 같은 특수 도구를 열 때 ATBCmder는 상황별 키맵을 활성화합니다. 이러한 바로 가기는 전역 응용 프로그램 전체 `cm_*` 레지스트리 명령을 통하지 않고 각 도구 창 내에서 직접 작동합니다.

## 6. 전문가 팁 및 시스템 단축키 최적화

### 6.1 macOS 전역 바로가기 충돌 해결

특정 기본 macOS 시스템 단축키는 데스크탑 애플리케이션에 도달하기 전에 키 누르기를 차단합니다. 전체 Commander 민첩성을 잠금 해제하려면 충돌하는 macOS 단축키를 사용자 정의하거나 비활성화할 수 있습니다. 

1. **스포트라이트 검색(`⌘Space` 대 빠른 검색)**: 
- 기본적으로 `⌘Space`은 Spotlight를 활성화합니다. 파일 표시 또는 패널 내 검색에 `⌘Space`을 사용하려는 경우 **시스템 설정 ➔ 키보드 ➔ 키보드 단축키... ➔ 스포트라이트**에서 Spotlight를 `⌥Space`로 다시 매핑하십시오. 
2. **미션 컨트롤(`⌃↑`) 및 앱 노출(`⌃↓`)**: 
- macOS는 Mission Control에 `⌃↑` 및 `⌃↓`을 사용합니다. ATBCmder에서 `⌃↓`은 디렉터리 기록 드롭다운을 엽니다. **시스템 설정 ➔ 키보드 ➔ 키보드 단축키... ➔ Mission Control**에서 Mission Control을 다시 할당할 수 있습니다. 
3. **애플리케이션 숨기기(`⌘H`)**: 
- macOS에서 `⌘H`은 맨 앞의 애플리케이션을 숨깁니다. ATBCmder는 `⌘H` 또는 `⇧⌘.`을 사용하여 숨겨진 도트 파일을 전환합니다. `⌘H`을 통해 숨겨진 파일을 엄격하게 전환하려면 macOS에서 "응용 프로그램 숨기기"를 비활성화하거나 Finder 표준 `⇧⌘.`(`Cmd+Shift+Period`)을 사용하세요. 
4. **창 최소화(`⌘M`)**: 
- macOS는 창을 Dock으로 최소화하기 위해 `⌘M`을 할당합니다. ATBCmder는 `⌘M`을 일괄 다중 이름 바꾸기 도구(`cm_MultiRename`)에 할당합니다. ATBCmder는 기본 창 내에서 `⌘M`을 캡처하지만 `Ctrl+M` 또는 도구 모음을 통해 다중 이름 바꾸기를 트리거할 수도 있습니다.

### 6.2 트랙패드 및 마우스 인체공학

외부 키보드가 없는 노트북 사용자를 위해 ATBCMder는 직관적인 트랙패드 제스처와 키보드 단축키를 결합합니다. 

* **손가락을 모아 썸네일 확대/축소**: 썸네일 보기(`cm_ThumbnailsView`)에서 MacBook 트랙패드를 핀치 인하거나 아웃하여(또는 `⌃`을 누른 채 스크롤) 썸네일 미리보기 크기를 `48 px`에서 최대 `512 px`까지 지속적으로 조정합니다. 
* **두 손가락으로 뒤로/앞으로 스와이프**: 폴더 기록을 통해 뒤로(`cm_ViewHistoryPrev`) 및 앞으로(`cm_ViewHistoryNext`) 탐색하려면 파일 테이블에서 두 손가락으로 왼쪽 또는 오른쪽으로 스와이프합니다. 
* **분할 두 번 클릭**: 수직 중앙 구분선의 아무 곳이나 두 번 클릭하면 패널이 정확히 50/50 수평 분할로 재설정됩니다. 
* **탭을 마우스 가운데 버튼으로 클릭**: `⌘W`을 누르지 않고도 폴더 탭을 마우스 가운데 버튼으로 클릭(또는 세 손가락 탭)하여 즉시 닫습니다.

### 6.3 환경 설정에서 키 바인딩 사용자 정의

위에 문서화된 모든 단축키는 사용자 정의하거나 리바인드할 수 있습니다. 

1. **`⌘,`**(또는 **구성 ➔ 옵션...** 선택)을 눌러 기본 설정 대화 상자를 엽니다. 
2. 사이드바에서 **핫키**를 선택합니다. 
3. **컨텍스트** 드롭다운을 사용하여 구성하려는 영역(`Main`, `FilePanel`, `Viewer` 등)을 선택합니다. 
4. 검색 필터 상자를 사용하여 이름이나 `cm_*` ID로 명령을 찾습니다. 
5. 바로가기 상자를 클릭하고 원하는 키 조합을 누르세요. 내장된 충돌 감지기는 해당 코드가 이미 다른 곳에 할당된 경우 즉시 경고합니다. 
6. 애플리케이션을 다시 시작하지 않고도 변경 사항을 즉시 활성화하려면 **적용**을 클릭하세요. 

사용자 키 바인딩은 `~/.config/atbcmder/atbcmder_hotkeys.xml`(또는 macOS에서는 `~/Library/환경설정/atbcmder/`)에 저장됩니다. **`cm_ExportConfiguration`**을 사용하여 이 파일을 여러 컴퓨터로 내보내고 전송할 수 있습니다.

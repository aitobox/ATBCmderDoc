# Глава 8: Справочник горячих клавиш

ATBCmder изначально разрабатывался как файловый менеджер, работающий с клавиатурой. Любая файловая операция, переход к каталогу, преобразование представления и пакетная утилита могут выполняться без вмешательства мыши. 

Чтобы соединить ортодоксальные традиции Commander с собственной эргономикой Apple, ATBCmder использует **Двухматричную архитектуру клавиатуры**: каждая команда может быть вызвана с помощью классических функциональных клавиш Commander (`F1`–`F12`, `Insert`, цифровая клавиатура) или родных аккордов-модификаторов macOS. (Команда `⌘`, опция `⌥`, сдвиг `⇧`, элемент управления `⌃`).

## 2. Основные указания по функции macOS (`Fn`)

> [!IMPORTANT] 
> ### Как использовать функциональные клавиши на клавиатуре Mac 
> 
> По умолчанию клавиатуры Apple (включая встроенные клавиатуры MacBook, Magic Keyboard и Touch Bar Mac) назначают верхний физический ряд (от `F1` до `F12`) для аппаратных элементов управления, таких как яркость дисплея, Mission Control, Spotlight, Dictation, воспроизведение мультимедиа и громкость динамика. 
> 
> Поскольку классические рабочие процессы Commander в значительной степени зависят от `F1`–`F12`, у вас есть два варианта: 
> 
> #### Способ A: удерживайте клавишу `Fn` (по умолчанию «из коробки») 
> Удерживайте физическую клавишу **`Fn`** (или клавишу с глобусом 🌐), расположенную в левом нижнем углу клавиатуры Mac, одновременно нажимая любую функциональную клавишу: 
> 
> * **`Fn + F3`**: просмотреть файл в Lister 
> * **`Fn + F4`**: Редактировать файл. 
> * **`Fn + F5`**: копирование файлов на целевую панель. 
> * **`Fn + F6`**: Переместить файлы на целевую панель. 
> * **`Fn + F7`**: Создать новый каталог. 
> * **`Fn + F8`**: Удалить файлы. 
> * **`Fn + Shift + F4`**: Создание и редактирование нового текстового файла. 
> * **`Fn + Alt + F7`**: Открыть поиск файлов 
> 
> #### Способ B: включите «Стандартные функциональные клавиши» в настройках macOS (рекомендуется) 
> Если вы регулярно используете ATBCmder, переключите строку функций так, чтобы нажатие `F1`–`F12` запускало функциональные команды напрямую, а удерживание `Fn` запускало регулировку яркости и громкости: 
> 
> 1. **macOS 13 Ventura, macOS 14 Sonoma, macOS 15 Sequoia**: 
> - Откройте ** Меню Apple ➔ Системные настройки...** 
> - На левой боковой панели выберите **Клавиатура**. 
> - Нажмите кнопку **Сочетания клавиш...**. 
> - На боковой панели диалогового окна выберите **Функциональные клавиши**. 
> - Переключите параметр ** «Использовать клавиши F1, F2 и т. д. в качестве стандартных функциональных клавиш»** на **ВКЛ**. 
> - Нажмите **Готово**. 
> 
> 2. **macOS 12 Monterey и macOS 11 Big Sur**: 
> - Откройте ** Меню Apple ➔ Системные настройки... ➔ Клавиатура**. 
> - На вкладке **Клавиатура** установите флажок **"Использовать клавиши F1, F2 и т. д. как стандартные функциональные клавиши"**. 
> 
> #### Модели MacBook Pro с сенсорной панелью 
> 
> * Удерживайте физическую клавишу **`Fn`** в левом нижнем углу, чтобы мгновенно отобразить виртуальную строку `F1`–`F12` на сенсорной панели. 
> * Альтернативно, настройте **Системные настройки ➔ Клавиатура ➔ Настройки сенсорной панели...** и установите для **"Touch Bar show"** значение **"F1, F2 и т. д. клавиши"**, когда ATBCmder является активным передним приложением. 
> 
> #### Компактные клавиатуры без специального функционального ряда 
> 
> * Если вы используете механическую клавиатуру с занятостью 60% или 65% без специальных клавиш `F`, вам не нужно сгибать пальцы. Используйте собственные аккорды-модификаторы macOS ATBCmder (`⌘C`, `⌥⌘V`, `⇧⌘N`, `⌘⌫`, `⌥⏎`), которые обеспечивают 100% операционную четность.

## 3. Контекстная архитектура ярлыков

Чтобы предотвратить конфликты горячих клавиш между различными областями приложения (например, поиск внутри основного списка файлов по сравнению с поиском в средстве просмотра текстовых файлов), ATBCmder сегментирует все ярлыки в отдельные иерархические контексты: 

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          APPLICATION SCOPE: Main                            │
│  Global commands, panel navigation, window management, toolbar, power tools │
├───────────────────────────────┬─────────────────────────────────────────────┤
│  PANEL SCOPE: FilePanel       │  MODAL TOOLS SCOPES                         │
│  Active during directory      │  • Viewer      (Lister preview window)      │
│  table and thumbnail browsing │  • Editor      (Built-in code editor)       │
│  (marking, range selection,   │  • Differ      (Side-by-side diff viewer)   │
│  inline editing, space count) │  • FindFiles   (Multi-threaded file search) │
│                               │  • MultiRename (Batch rename engine)        │
└───────────────────────────────┴─────────────────────────────────────────────┘
```
 

Когда вы нажимаете клавишу, механизм **`HotkeyManager`**: 

1. Оценивает активный сфокусированный контекст (например, `Viewer` или `FilePanel`). 
2. Если точная привязка совпадает, соответствующая команда `cm_*` выполняется немедленно. 
3. Если в локальном контексте привязки не существует, нажатие клавиши корректно возвращается в контекст `Main`. 
4. Если привязка еще не привязана, вступает в силу стандартное редактирование текста или системная обработка нажатий клавиш.

## 6. Советы профессионалов и оптимизация горячих клавиш системы

### 6.1 Разрешение глобальных конфликтов ярлыков macOS

Некоторые системные горячие клавиши macOS по умолчанию перехватывают нажатия клавиш до того, как они достигнут настольных приложений. Чтобы разблокировать полную гибкость Commander, вы можете настроить или отключить конфликтующие ярлыки macOS: 

1. **Поиск Spotlight (`⌘Space` вместо быстрого поиска)**: 
- По умолчанию `⌘Space` активирует Spotlight. Если вы предпочитаете использовать `⌘Space` для маркировки файлов или поиска на панели, переназначьте Spotlight на `⌥Space` в **Системные настройки ➔ Клавиатура ➔ Сочетания клавиш... ➔ Spotlight**. 
2. **Управление полетами (`⌃↑`) и разоблачение приложений (`⌃↓`)**: 
- macOS использует `⌃↑` и `⌃↓` для управления полетами. В ATBCmder `⌃↓` открывает раскрывающийся список «История каталогов». Вы можете переназначить Mission Control в **Настройки системы ➔ Клавиатура ➔ Сочетания клавиш... ➔ Mission Control**. 
3. **Скрытие приложения (`⌘H`)**: 
- В macOS `⌘H` скрывает самое переднее приложение. ATBCmder использует `⌘H` или `⇧⌘.` для переключения скрытых точечных файлов. Если вы хотите, чтобы `⌘H` строго переключал скрытые файлы, отключите «Скрыть приложение» в macOS или используйте стандарт Finder `⇧⌘.` (`Cmd+Shift+Period`). 
4. **Сворачивание окна (`⌘M`)**: 
- macOS назначает `⌘M`, чтобы свернуть окно в Dock. ATBCmder назначает `⌘M` инструменту пакетного множественного переименования (`cm_MultiRename`). ATBCmder захватывает `⌘M` в своем главном окне, но вы также можете запустить множественное переименование через `Ctrl+M` или панель инструментов.

### 6.2 Эргономика трекпада и мыши

Для пользователей ноутбуков без внешней клавиатуры ATBCmder сочетает сочетания клавиш с интуитивно понятными жестами трекпада: 

* **Сведите пальцы, чтобы увеличить миниатюры**. В режиме просмотра миниатюр (`cm_ThumbnailsView`) сведите или разведите пальцы на трекпаде MacBook (или удерживайте `⌃` и прокрутите), чтобы плавно изменять размер миниатюр предварительного просмотра от `48 px` до `512 px`. 
* **Проведение двумя пальцами назад/вперед**: проведите двумя пальцами влево или вправо по таблице файлов, чтобы перейти назад (`cm_ViewHistoryPrev`) и вперед (`cm_ViewHistoryNext`) по истории папок. 
* **Разделение двойным щелчком**: дважды щелкните в любом месте вертикального центрального разделителя, чтобы сбросить панели к точному горизонтальному разделению 50/50. 
* **Щелкните средней кнопкой мыши по вкладкам**: щелкните средней кнопкой мыши (или коснитесь тремя пальцами) любой вкладки папки, чтобы немедленно закрыть ее, не нажимая `⌘W`.

### 6.3 Настройка сочетаний клавиш в настройках

Каждый ярлык, описанный выше, можно настроить или перенастроить: 

1. Нажмите **`⌘,`** (или выберите **Конфигурация ➔ Параметры...**), чтобы открыть диалоговое окно «Настройки». 
2. Выберите **Сочетания клавиш** на боковой панели. 
3. В раскрывающемся списке **Контекст** выберите область, которую вы хотите настроить (`Main`, `FilePanel`, `Viewer` и т. д.). 
4. Используйте поле фильтра поиска, чтобы найти любую команду по имени или идентификатору `cm_*`. 
5. Щелкните поле быстрого доступа и нажмите нужную комбинацию клавиш. Встроенный детектор столкновений немедленно предупредит вас, если этот аккорд уже назначен где-то еще. 
6. Нажмите **Применить**, чтобы мгновенно активировать изменения без перезапуска приложения. 

Пользовательские сочетания клавиш сохраняются в `~/.config/atbcmder/atbcmder_hotkeys.xml` (или `~/Library/Настройки/atbcmder/` в macOS). Вы можете экспортировать и передавать этот файл между компьютерами, используя **`cm_ExportConfiguration`**.

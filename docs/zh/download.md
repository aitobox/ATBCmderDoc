# 第 11 章：软件下载与安装指南

感谢您对 ATBCmder 的关注与支持！我们提供两种便捷的安装方式，满足不同的使用偏好与场景需求。

> [!IMPORTANT]
> **系统与硬件芯片要求**  
>
> - **支持系统**：macOS 12.0 (Monterey) 及更高版本（全面兼容 macOS 13 Ventura、macOS 14 Sonoma 与 macOS 15 Sequoia）。  
> - **硬件架构支持**：**Universal 通用双架构（Apple Silicon ARM64 与 Intel x86_64）**。全面支持 Apple Silicon (M1 / M2 / M3 / M4) 与 Intel 架构 Mac 电脑。  
> - **Intel (x86_64) 架构说明**：自 1.8.0 版本起已全面原生支持 Intel (x86_64) 架构。

## 1. Mac App Store 商店版（推荐）

这是最推荐普通用户选择的安装方式。**ATBCmder 现已正式上架 Mac App Store！** 通过官方商店下载，可享受全自动后台静默更新、原生 macOS 应用沙盒安全保护以及最深度的系统级整合。

- **Mac App Store 官方下载**：[在 Mac App Store 中下载 ATBCmder](https://apps.apple.com/app/atbcmder/id6792398333)

## 2. 独立 DMG 安装包下载

若您无法访问 Mac App Store，或偏好直接使用独立分发版本，我们同时提供支持 Universal 双架构（Apple Silicon ARM64 与 Intel x86_64）原生构建的 DMG 磁盘映像安装包。

- **DMG 安装包直接下载**：[点击下载最新版 ATBCmder DMG 镜像](https://storage.aitobox.com/@s/bNAshV6G/ATBCmder)（Universal 通用双架构：Apple Silicon 与 Intel x86_64）

*注意：通过 DMG 首次打开应用时，macOS 安全机制可能会提示“无法打开或未验证的应用”。只需前往 **系统设置 > 隐私与安全性**，点击“仍要打开”即可正常运行。*

### ⚠️ 授予“完全磁盘访问权限”

ATBCmder 作为专业级双面板文件管理器，需要访问并管理您的全盘文件。为保证全部功能顺畅运行，请按照以下步骤授予权限：

1. 点击屏幕左上角 Apple 图标（），打开 **系统设置**（较早的 macOS 版本中为“系统偏好设置”）。
2. 在左侧或主菜单中找到并点击 **隐私与安全性**。
3. 向下滚动列表，点击进入 **完全磁盘访问权限**（Full Disk Access）。
4. 在应用列表中找到 **ATBCmder** 并打开右侧开关。若列表中未显示，可点击下方的 **+** 号按钮手动添加 。
5. 系统将提示您输入 Mac 登录密码或轻触 Touch ID 确认更改。

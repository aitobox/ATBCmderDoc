# 第 2 章：导航、标签页与视图模式

在错综复杂的目录树中行云流水般极速穿梭，是正统双面板文件管理器的灵魂所在。在 ATBCmder 中，您再也不用费劲去拖拽细小的滚动条、一层层重复双击点开深层文件夹，或者被几十个凌乱重叠的访达 (Finder) 窗口搞得头昏眼花。

本章将带您全方位掌握本地与远程文件系统的高速巡航技巧：交互式路径面包屑、键盘闪电跳级、macOS 原生多标签页体系、双面板常用标签组持久化工作区、支持实时模糊匹配的书签热键列表，以及 5 大专业面板视图模式。

## 2. 基础目录导航：路径、面包屑与快捷键

ATBCmder 提供多种符合人体工学的自由导航方式——无论您偏好触控板手势、鼠标指针还是纯键盘操控。

### 鼠标与触控板直觉操作

- **进入文件夹**：在任意文件夹条目上双击鼠标，或按下回车键 (`Return`)。
- **返回上一级**：双击列表顶部的 `[..]` 行，直接回退到父级目录。
- **后台静默打开标签**：在任意文件夹上**轻点鼠标中键**（或触控板三指轻击），即可在后台新标签页中打开该目录，保持当前面板视图不中断 (`cm_OpenDirInNewTab`)。

### 访达风格可交互路径面包屑栏

位于每个文件面板正上方的交互式面包屑栏，将当前的 UNIX 路径拆解为一系列可直接点击的节点：

```
🏠 / ▸ Users ▸ brain ▸ Projects ▸ ATBCmder ▸ docs
```

1. **祖先节点秒级跳级**：直接点击路径中的任意祖先文件夹（如 `Projects` 或 `Users`），即可跳过多次逐级回退，瞬间直达该层级。
2. **同级子目录级联直达**：鼠标悬停或点击节点间的展开小箭头 (`▸`)，会弹出一个精致的下拉子菜单，列出该层级下的所有兄弟文件夹，点击即可直接切换。
3. **右键实用工具菜单**：右键点击任意面包屑节点，可呼出上下文菜单：
   - **在新标签页中打开**：保持现有窗口不变，将该目录在独立标签页中载入。
   - **在访达中显示**：在 macOS Finder 中直接揭示该文件夹 (`open -R`)。
   - **复制路径**：一键将该节点的绝对 UNIX 完整路径复制到剪贴板。
   - **在终端中打开**：以此目录作为工作路径，瞬间启动 macOS 终端。
4. **地址栏直接键入模式 (`BreadcrumbLineEdit`)**：
   - 双击面包屑链条右侧的空白区域（或按下 `Shift+F2`）。
   - 面包屑条立即变为可自由输入的文本编辑框 (`QLineEdit`)。
   - 直接粘贴或输入任意路径（例如 `~/Library/Application Support`、`/var/log`、`/Volumes/ExternalDrive` 或 `vfs://` 压缩包虚拟路径）。
   - 按 `Enter` 回车直达，或按 `Esc` 取消并还原为面包屑按钮。

### 闪电级键盘跳跃

保持双手不离主键区的高效导航按键：

- **返回父目录 (`Backspace` / `⌘↑` / `Ctrl+PgUp` / `cm_ChangeDirToParent`)**：跳出当前文件夹。回退时，ATBCmder 会自动将光标精准锁定在您刚刚退出的那个文件夹上，绝不会迷失位置。
- **直达系统根目录 (`Ctrl+\` / `cm_ChangeDirToRoot`)**：一键跳到 macOS 根磁盘根节点 (`/`)。
- **直达用户主目录 (`Ctrl+Shift+Home` / `cm_ChangeDirToHome`)**：一键返回您的个人家目录 (`/Users/username` 或 `~`)。
- **首尾定位**：按 `Home` 键光标跳至第一行 (`..`)，按 `End` 键跳至列表中最后一个文件。

## 3. 文件夹标签页：在面板内从容多任务

面对复杂的软件项目、照片素材库或网络备份时，我们往往需要在多个目录间来回协同。与其在桌面上堆砌十几层窗口，ATBCmder 为左右两侧面板分别配备了独立的多标签页栏。

![文件夹标签页与快捷访问](images/quick_access_paths.png)  
*ATBCmder 多标签页管理与路径直达*

### 原生 macOS 风格标签栏设计

基于 `MacNativeTabBar` 打造，完美融合 macOS 现代美学：

- **圆角胶囊质感**：圆润的标签边角、平滑的悬停微动效与清晰的当前标签高亮条。
- **悬停关闭小叉**：鼠标悬停或选中标签时，右侧自动浮现关闭按钮 (`✕`)。
- **鼠标中键随手关**：中键点击任意标签（或触控板三指轻敲）即可瞬时关闭。
- **双击空白新建**：在标签栏空白处双击鼠标，即可快速复制当前路径新建一个标签页。

### 标签页常用操作与快捷键

| 操作名称 | macOS 快捷键 | 传统按键 | 命令 ID | 功能说明 |
| :--- | :--- | :--- | :--- | :--- |
| **新建标签页** | `Cmd+T` / `⌘T` | `Ctrl+T` | `cm_NewTab` | 以当前所在目录打开一个新标签页。 |
| **关闭当前标签** | `Cmd+W` / `⌘W` | `Ctrl+W` | `cm_CloseTab` | 关闭当前标签（面板至少保留 1 个标签）。 |
| **切换至下一个标签**| `Ctrl+Tab` / `⌃⇥` | `Ctrl+Tab` | `cm_NextTab` | 焦点向右轮换至下一个标签页。 |
| **切换至上一个标签**| `Ctrl+Shift+Tab` | `Ctrl+Shift+Tab`| `cm_PrevTab` | 焦点向左轮换至上一个标签页。 |
| **展开标签页清单** | `Ctrl+Shift+L` | `Ctrl+Shift+L` | `cm_ShowTabsList` | 弹出当前面板全部已开标签的数字编号列表。 |
| **重命名标签页** | *右键点击标签* | — | `cm_RenameTab` | 为标签页设置自定义易记别名。 |
| **关闭其他标签页** | *右键点击标签* | — | `cm_CloseOtherTabs` | 一键关闭除当前标签以外的所有标签页。 |
| **关闭重复标签页** | *右键点击标签* | — | `cm_CloseDuplicateTabs`| 自动扫描并关闭路径完全重复的多余标签。 |
| **关闭所有标签页** | *标签页菜单* | — | `cm_CloseAllTabs` | 一键重置清空，恢复仅保留 1 个标签。 |
| **复制所有标签至对侧**| *标签页菜单* | — | `cm_CopyAllTabsToOpposite`| 将当前面板的整套标签页镜像复制到对侧面板。 |

### 标签页锁定模式 (Tab Locking)

在核心业务或关键目录中，为了防止误触翻页跳出当前文件夹，您可以为标签页设置锁定保护。右键点击任意标签页：

1. **常规模式 (未锁定)**：
   - 默认状态，进入子目录或切换路径时直接在当前标签中跳转。
2. **严格锁定 (`cmd_SetTabOptionLock`)**：
   - 标签路径完全冻结在当前初始目录。
   - 标签标题左侧显示醒目的锁定图标（`🔒` 或 `★`）。
   - 当您在该标签中双击进入子文件夹或尝试跳转时，ATBCmder 会原样保持该锁定标签不变，并**在右侧自动新建一个独立标签页**打开目标子目录。
3. **锁定但允许进入子目录 (`cmd_SetTabOptionLockWithSubdirs`)**：
   - 允许您在此目录树内部自由向深层子文件夹游历浏览。
   - 但严格禁止退回到高于此基准目录的上层。
   - 当您切换走或刷新时，该标签会自动重置回到锁定的根节点。

## 4. 常用标签组 (Favorite Tabs)：双面板工作区一键复原

如果说单个标签页解决的是局部灵活性，那么 **常用标签页组 (Favorite Tabs)** 解决的则是整个工作场景的快速搭建——只需一条指令，瞬间还原左右两侧由多个标签组成的完整生产环境。

```
┌────────────────────────────────────────┐
│ 常用标签页组合: "客户端发版工作区"     │
├───────────────────┬────────────────────┤
│ 左面板标签页群组  │ 右面板标签页群组   │
│ 1. [★ src/api]    │ 1. [build/dist]    │
│ 2. [docs/guides]  │ 2. [vfs://sftp/nas]│
│ 3. [tests/unit]   │ 3. [~/Downloads]   │
└───────────────────┴────────────────────┘
```

一个常用标签页组完整封装了：

- 左侧面板打开的所有标签页（包含各自路径与锁定状态）。
- 右侧面板打开的所有标签页（包含各自路径与锁定状态）。
- 左右两侧当前正被激活聚焦的标签页位置。

### 常用标签页组核心功能

- **保存当前标签组合 (`cm_SaveFavoriteTabs`)**：
  - 点击菜单栏 **收藏** → **将当前标签保存为新的常用标签组**，或右键点击标签栏空白处。
  - 为工作区输入命名（例如：`Web 后端开发`、`2026 照片归档` 或 `服务器运维部署`）。
  - 配置将持久保存于配置目录的 `fav_tab_config.xml` 中。
- **加载常用标签组合 (`cm_LoadFavoriteTabs`)**：
  - 点击菜单栏 **收藏** → **加载常用标签组**。
  - 弹出已存工作区列表，双击选定，左右两侧面板瞬间根据保存的布局完成全套重置与恢复。
- **更新覆盖当前工作区 (`cm_ResaveFavoriteTabs`)**：
  - 当您在某个工作区中调整了标签或路径，无需重复输入名称，直接以此命令静默更新已存配置。
- **重新载入初始状态 (`cm_ReloadFavoriteTabs`)**：
  - 随时丢弃当前会话中临时点开的探索标签，让两侧面板迅速复原到该工作区最初保存的纯净状态。
- **工作区轮换 (上一个 / 下一个标签组)**：
  - 在多个项目工作区之间快速按顺序线性轮转切换。
- **统一配置管理 (`cm_ConfigFavoriteTabs`)**：
  - 打开 **偏好设置** → **常用标签页**，在此可自由拖拽排序、批量重命名工作区、手动微调某标签的路径或清理废弃方案。

## 5. 常用目录书签 (Directory Hotlist)

**常用目录书签 (Directory Hotlist)** 是 ATBCmder 中高频触发的全局任意门，可跨越本地内置硬盘、外接存储设备以及挂载的局域网共享，实现两秒内精准直达。

![常用目录书签](images/quick_access_paths.png)  
*支持实时模糊搜索的常用目录书签弹出面板*

### 秒级书签呼出 (`Ctrl+D` / `⌃D` / `cm_DirHotList`)

轻按 `Ctrl+D`，屏幕中央立即浮现轻量化快捷搜索面板：

1. **全实时模糊拼音/英文检索**：
   - 键盘直接敲击字符，搜索框会实时对书签名称与目标路径进行模糊匹配过滤。
   - 例如输入 `down`，列表立即筛选出 `下载目录 — /Users/username/Downloads`。
2. **键盘流畅确认**：
   - 使用上下方向键 (`↑` / `↓`) 高亮目标项。
   - 敲击 `Enter` 回车，当前激活面板立即穿梭至目标路径。
   - 敲击 `Esc` 随手收起弹窗，面板路径保持不变。
3. **当前路径一键入库**：
   - 在弹窗内点击 **“添加当前目录”** 按钮（或按 `Alt+A`）。
   - ATBCmder 会自动将当前路径填入，并预推一个简洁明了的默认书签名称。

### 书签结构化配置 (`Ctrl+Shift+D` / `⌃⇧D` / `cm_ConfigDirHotList`)

打开 **偏好设置** → **常用目录**（或执行 `cm_ConfigDirHotList`），对您的个人书签进行专业组织：

- **树状多级子目录归类**：支持建立层级分类（如 `开发工作`、`个人生活`、`云盘同步`、`网络 NAS 挂载`）。
- **自定义友好别名**：用通俗的 `工作文档` 替代冗长难记的物理路径 `/Users/username/Library/Mobile Documents/com~apple~CloudDocs/Work`。
- **拖拽排序优先级**：将日常最密集的几处文件夹拖放至最前排。

## 6. 历史记录与驱动器切换：穿梭时空与存储卷

ATBCmder 为每一次浏览都留下了清晰的历史足迹，让您可以像浏览网页一样随时回溯。

### 路径游历历史记录

左右两侧面板各自维护一套独立的浏览时间线：

- **后退 (`Cmd+[` / `⌘[` 或 `Alt+Left` / `cm_ViewHistoryPrev`)**：退回上一个浏览过的目录。
- **前进 (`Cmd+]` / `⌘]` 或 `Alt+Right` / `cm_ViewHistoryNext`)**：后退之后重新前进到下一个目录。
- **历史记录弹窗 (`Alt+F8` / `⌥F8` 或 `Ctrl+Down` / `⌃↓` / `cm_DirHistory`)**：
  - 呼出一个下拉列表，展示当前面板最近访问过的 20+ 个文件夹。
  - 直接方向键选中即可跳转，免去连续按十几次“后退”键的繁琐。

### 磁盘驱动器与外置存储卷切换

在 macOS 中，所有内置主硬盘分区、外接 USB-C / 移动雷电硬盘、挂载的 DMG 镜像以及局域网 SMB 共享均统一挂载在 `/Volumes` 之下。ATBCmder 提供高效的专用盘符切换指令：

![磁盘驱动器与挂载卷宗快速切换](images/driver_select.png)  
*按 Alt+F1（左面板）、Alt+F2（右面板）或 Alt+D 弹出的驱动器与卷宗快速选择列表*

- **左侧面板驱动器切换 (`Alt+F1` / `⌥F1` / `cm_LeftOpenDrives`)**：正统 Commander 核心快捷键，专为左侧面板呼出驱动器与磁盘卷选取菜单。
- **右侧面板驱动器切换 (`Alt+F2` / `⌥F2` / `cm_RightOpenDrives`)**：正统 Commander 核心快捷键，专为右侧面板呼出驱动器与磁盘卷选取菜单。
- **全局当前面板磁盘菜单 (`Alt+D` / `⌥D` / `cm_Drives`)**：为当前处于激活焦点的面板弹出系统全部已挂载磁盘卷、系统根目录 `/`、用户家目录 `~` 以及已连网络端点的切换列表。

> [!NOTE]
> **外接磁盘沙盒访问授权**：当首次访问 `/Volumes` 下新挂载的外接磁盘时，系统沙盒可能会触发安全边界，ATBCmder 会自动弹出授权对话框，为该存储介质签发长效持久的安全书签。

## 7. 五大面板视图模式：随工作场景自由定制

ATBCmder 提供 5 种各有所长的视图模式，帮您在不同的文件管理任务中把屏幕利用率和信息呈现效率发挥到极致。

### 1. 详细多列列表 (`Ctrl+F2` / `⌃F2` / `cm_ColumnsView`)

最经典、功能最全面的信息视图，以规整的表格列呈现全部元数据：

| 属性列 | 内容含义 | 对齐方式 |
| :--- | :--- | :--- |
| **名称** | 文件或文件夹全称，带系统原生文件类型图标。 | 靠左对齐 |
| **扩展名** | 文件扩展名类型（如 `py`、`png`、`zip`）。 | 靠左对齐 |
| **大小** | 格式化后的物理容量 (B, KB, MB, GB)，文件夹标为 `<目录>`。 | 靠右对齐 |
| **修改日期** | 遵循本地化时间格式的精确修改时间戳。 | 靠左对齐 |
| **属性权限** | UNIX 文件系统权限（如 `0755` 与 `drwxr-xr-x`）。 | 居中对齐 |
| **所有者/组** | 文件归属的系统用户名与用户组。 | 靠左对齐 |

- **列头点击即时排序**：点击任意列头在升序与降序之间快速切换；按住 `Cmd` 点击其他列头还可开启二级混合联合排序。

### 2. 简要紧凑视图 (`Ctrl+F1` / `⌃F1` / `cm_BriefView`)

剥除多余的属性字段，将整个面板空间均分为多个紧凑的并排垂直列，仅展示文件名与图标。

- **超高信息密度**：同屏能够展现的文件数量是详细列表的 3 到 5 倍。
- **最佳应用场景**：字体库、大批量照片包、日志归档等超大文件夹，只需快速辨认名称、不需要逐行对比大小时间时，使用简要视图最为迅速。

### 3. 缩略图画廊视图 (`Ctrl+Shift+F1` / `⌃⇧F1` / `cm_ThumbnailsView`)

将文件列表自动转换为视觉优先的卡片图标网格。

![缩略图画廊视图](images/thumbnails_grid_view.png)  
*在活动面板中以缩略图网格渲染图片与多媒体文件*

- **多媒体全格式覆盖**：对常用图片（JPEG、PNG、HEIC、TIFF、WebP、GIF）、矢量格式（SVG）、PDF 封面及视频文件（MP4、MOV、MKV）提供即时高清生成。
- **后台异步极速渲染**：缩略图提取全程运行于独立的后台 I/O 线程池中，快速拖动列表绝不卡死主界面。
- **尺寸自由微调**：在 **偏好设置** → **文件视图** 中，可随意将缩略图边长从 64px 调节至 256px，更支持在列表中按住 `Cmd + 滚轮` 进行无级动态缩放。

### 4. 树状目录导航视图 (`cm_TreeView`, `cm_TreeViewSplit`, `cm_TreeViewBoth`)

以树形结构逐级展开整个文件系统的目录脉络，深层层级一收一放，清晰明了。

![树状视图与缩略图混合](images/treeview+thumbview.png)  
*树状目录与右侧缩略图并排呈现*

通过菜单栏 **显示**，ATBCmder 支持三种自由布局组合：

- **树状视图 (替换模式) (`cm_TreeView`)**：当前面板完整替换为展开式目录树。
- **树状视图 (左右分栏模式) (`cm_TreeViewSplit`)**：当前面板在内部垂直一分为二，左侧为目录树，右侧则是选中文件夹的常规文件列表。
- **双面板全开树状视图 (`cm_TreeViewBoth`)**：让左右两侧面板同时开启内部树状分栏。
- **是否展示文件开关**：在树状视图中右键，可自由勾选“显示文件”，决定是只展示纯文件夹骨架还是连同文件一并列出。

### 5. 平铺扁平视图 / 分支视图 (`Cmd+B` / `⌘B` 或 `Ctrl+B` / `cm_FlatView`)

**扁平视图 (Branch / Flat View)** 是 ATBCmder 最令人惊叹的黑科技之一。它能够递归穿透当前文件夹下的**所有多层级子目录**，把所有深埋在内部的文件一口气提拔、平铺展示在**一个统一的大列表中**！

![扁平平铺分支视图](images/branch_view.png)  
*按 `Cmd+B` 展开包含多层子文件夹的扁平化视图*

- **新增路径属性列**：开启扁平视图后，表格会自动插入一列 **路径 (Path)**，清晰注明每个文件原本藏在哪一层相对目录中（如 `assets/icons/` 或 `src/core/`）。
- **跨层级全局排序**：将整个工程项目下散落在几十个子文件夹里的文件，统一按照“文件大小”或“最后修改时间”拉通排序。
- **批量一网打尽**：不需要一层层钻进文件夹逐个收集，在扁平视图中按 `Cmd+A` 全选，直接按 `F5` 复制、`F6` 移动或 `Ctrl+M` 批量重命名。
- **流式增量渲染**：即便面对包含数万个深层文件的庞大目录，后台遍历线程也会边扫描边流式送入列表，UI 保持丝滑交互。
- **一键复原**：再次按下 `Cmd+B`（或 `Ctrl+B`），面板立刻从扁平状态退回原本的常规文件夹模式。

## 8. ⚡ 极客进阶：精准控制与微调

专为追求极致操控的高级玩家与键盘党准备的高阶技巧：

### 面板内即时快速搜索条 (`Ctrl+S` / `⌃S` / `cm_QuickSearch`)

无需调用庞大的全局搜索窗口，在当前目录按键即刻跳转：

```
┌─────────────────────────────────────────────────────────────────┐
│  main.py            py      8.4 KB    今天 15:10     -rw-r--r-- │
│  main_window.py     py     72.1 KB    今天 15:18     -rw-r--r-- │
├─────────────────────────────────────────────────────────────────┤
│ 🔍 快捷搜索: main_                   [ 下一项: ↓ ] [ 上一项: ↑ ]│
└─────────────────────────────────────────────────────────────────┘
```

1. **增量即输即搜**：
   - 按下 `Ctrl+S`（若在设置中勾选了“字母直接驱动”，则直接在键盘上敲字母即可）。
   - 面板下方弹出精巧的搜索浮条。
   - 随着字符输入，列表光标实时跳向首个符合前缀匹配的文件。
2. **前后匹配轮跳**：
   - 按下方向键 `↓` 跳至下一个匹配项。
   - 按下方向键 `↑` 跳回上一个匹配项。
   - 按 `Enter` 回车直接打开该项。
   - 按 `Esc` 退出搜索条，光标停留在最后匹配到的文件上。
3. **尾随句点小妙招**：
   - 如果想精准定位文件名主体，可以输入一个结尾句点（如 `config.`），从而精确命中 `config.xml`，自动避开 `configuration_guide.md`。
4. **快搜、快筛与语义搜索的区别**：
   - **快速搜索 (`Ctrl+S` / `cm_QuickSearch`)**：光标在不同匹配项间上下跳动定位，周围不匹配的文件依然可见。
   - **快速过滤 (`cm_QuickFilter`)**：临时隐藏不匹配的文件，列表里只留符合条件的条目。
   - **语义搜索 (`Ctrl+F` / `cm_SemanticFilter`)**：借助 macOS Spotlight，输入自然语言进行语义检索（如 `/大于 10MB`、`//今天修改的 pdf`）。

### 表格列宽智能自适应规则

厌倦了每次手动拉扯列宽，或者总是被截断的文件名折磨？在 **偏好设置** → **文件视图** 中，您可以指定三种列宽引擎：

1. **最大文本宽度 (`mode="max"`)**：
   - 自动扫描当前可见的所有文件全名，把“名称”列撑到刚好能够完整阅读最长文件名的宽度，彻底杜绝出现省略号 (`...`)。
2. **统计平均宽度 (`mode="average"`, 默认推荐)**：
   - 计算文件名字符的统计均值，乘以边距权重因子 (`auto_fit_padding`, 默认 `1.0`) 并加上图标留白。
   - **独特优势**：防止单个偶然出现的 150 字符超长文件名把大小、时间等重要信息挤出屏幕外。
3. **固定列宽 (`mode="fixed"`)**：
   - 严格固定每个属性列的像素数值。
   - 只要您在列表中手动拖动过一次表头分割线，系统会自动切换为此模式，充分尊重您的排版偏好。

### 水平分栏堆叠模式 (`Ctrl+Shift+H` / `⌃⇧H` / `cm_HorizontalFilePanels`)

默认的左右分栏模式适合多数宽屏操作。而在遇到超宽属性列比对或垂直显示屏时，您可以随时切换为上下堆叠模式：

![水平双面板模式](images/horizontal_panels_view.png)  
*上下排布的水平双面板展示*

- 按快捷键 `Ctrl+Shift+H` 或在菜单栏选择 **显示** → **水平双面板**。
- 双面板操作原则完全不变：操作指令自然在上方主面板与下方副面板之间流转。

### 标签页独立视图配置持久化

在许多简易文件管理器中，只要改动一次排序列或切换到缩略图，所有标签页都会被强行全局修改。

而在 ATBCmder 中，**每个标签页拥有完全独立的显示状态 (`TabState`)**，并由 `SessionManager` 自动写入 `atbcmder_session.xml` 实现跨会话无缝还原：

- **视图模式互不干扰**：标签页 1 设置为 **详细列表** 用于排查代码，标签页 2 设置为 **缩略图视图** 挑拣图片，标签页 3 设置为 **简要视图** 快速浏览，三者并存互不影响。
- **排序规则各自记忆**：每个标签页各自记住按哪一列排、是升序还是降序。来回切换标签页，您的排序逻辑永远不会被打乱。
- **扁平/树状视图独立生效**：某个标签开启了 **扁平平铺分支视图** (`Cmd+B`) 或 **树状视图**，其他标签依旧安安静静保持常规文件夹展示。

## 9. 手把手实战教程

三组贴合真实日常的连贯实战操作：

### 食谱 1：搭建永不丢失的全栈开发常驻工作区

**目标**：配置一套左右协同的双面板前端/后端项目环境，并支持日后一键秒级还原。

1. **配置左侧面板（源码仓库）**：
   - 浏览至 `~/Projects/MyApp/src`。
   - 按 `Cmd+T` 开启新标签，浏览至 `~/Projects/MyApp/tests`。
   - 在 `src` 标签页上右键，点击 **锁定标签** (`cmd_SetTabOptionLock`)。
2. **配置右侧面板（编译构建与日志）**：
   - 按 `Tab` 键将焦点转到右侧面板。
   - 浏览至 `~/Projects/MyApp/dist`。
   - 按 `Cmd+T` 开启新标签，浏览至系统日志目录 `/var/log`。
3. **保存为常用工作区**：
   - 点击菜单栏 **收藏** → **将当前标签保存为新的常用标签组** (`cm_SaveFavoriteTabs`)。
   - 键入名称 `MyApp 完整开发环境`，敲击回车保存。
4. **随用随调**：
   - 无论日后窗口被怎样关闭或修改，只需在菜单栏点击 **收藏** → **加载常用标签组** (`cm_LoadFavoriteTabs`)，选择该方案，所有四个标签及锁定状态即刻精准重现！

---

### 食谱 2：穿透多层文件夹，瞬间清理巨型冗余文件

**目标**：在层层嵌套的工程目录中，揪出分散在各处的超大垃圾测试数据和陈旧日志。

1. 在当前面板中进入目标项目的根目录。
2. 按下 `Cmd+B`（或 `Ctrl+B`）激活 **平铺扁平视图 (Branch View)**。
3. 稍等片刻，所有嵌套在子目录深处的文件被全部平铺在一个列表中。
4. 点击表头的 **大小 (Size)** 列，进行降序排列（从大到小）。
5. 整个项目树中体积最大的文件瞬间整齐排在最前几行，旁边的 **路径** 列清晰告知您它们各自蜷缩在哪一层文件夹里。
6. 直接按 `F8` 将确定不需要的大文件删入废纸篓。
7. 再次按下 `Cmd+B`，平稳退出扁平模式，恢复常规目录层次。

---

### 食谱 3：为局域网 NAS 常用备份路径建立极速直达书签

**目标**：为远程 NAS 文件夹添加书签，今后敲两下按键即可直达。

1. 浏览进入挂载好的网络存储目录（例如 `/Volumes/BackupShare/Archives`）。
2. 按下 `Ctrl+D` 呼出常用目录书签面板。
3. 点击面板中的 **“添加当前目录”** 按钮 (`cm_AddDirToHotlist`)。
4. 命名为 `NAS 归档备份`。
5. 明天当您在 Mac 任何角落需要传输文件时，只需轻按 `Ctrl+D`，输入 `nas`，敲回车——ATBCmder 瞬间跨网络带您直达该目标文件夹！

## 10. 安全与系统提示

> [!NOTE]
> **外置存储卷与网络共享提示**：
> 当标签页或书签指向外接移动盘或局域网共享 (`/Volumes/...`) 时，若该磁盘当前未连入系统，ATBCmder 启动时会在标签页上友好提示“路径暂不可用”，绝不会异常崩溃或强行抹掉该标签。

> [!TIP]
> **一键对向克隆所有标签页**：
> 如果想让右侧面板完全复制左侧面板刚刚辛辛苦苦打开的一整排标签页，只需点击菜单栏 **标签页** → **复制所有标签至对侧面板** (`cm_CopyAllTabsToOpposite`)。

> [!WARNING]
> **扁平视图 (`Cmd+B`) 下的批量操作注意事项**：
> 在扁平分支视图下，来自不同子目录的文件被汇集在同一列表中。此时如果使用 `Cmd+A` 全选并按下 `F8` 删除或 `F6` 移动，该操作将会递归作用于所有深层子目录内的匹配文件，请在确认执行前稍加核对提示信息。

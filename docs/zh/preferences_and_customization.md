# 第 7 章：偏好设置与个性化定制

一款真正卓越的文件管理器应当主动适应您的工作节奏，而不是强迫您去削足适履。资深工程师、系统管理员、数字档案管理人员与设计创作者各自拥有截然不同的肌肉记忆、视觉需求与操作习惯：有人严格恪守传统 Norton Commander / Total Commander 的经典功能键（`F1`–`F10`），有人则深度依赖 macOS 原生快捷键（`Cmd+C`、`Cmd+V`、`Cmd+O`）；有人要求表格列宽根据文件名排版指标实时智能自适应，有人则偏好边界分明、严格锁定的固定列宽；有人需要毫秒级的实时文件系统变动监听，有人则在跨洋高延迟网络共享盘上工作，必须强制启用温和的周期性轮询机制。

ATBCmder v1.7.0 从底层架构起便具备极高的可定制性。通过高度模块化的 **综合偏好设置中心** (`Cmd+,` / `⌘,` / `cm_Options`)、直观且自带实时冲突检测的 **图形化快捷键编辑器**、智能的 **列宽自适应算法引擎**、支持丰富动态宏参数的文件类型关联规则，以及支持一键打包迁移的 **ZIP 便携配置包** (`cm_ExportConfiguration`)，ATBCmder 允许您随心微调双面板环境的每一个细节，并在多台 Mac 之间自由无缝穿梭。

## 2. 偏好设置中心结构与操作指南 (`Cmd+,` / `cm_Options`)

ATBCmder 的总控控制台就是 **偏好设置对话框**。您可以通过按下 **`Cmd+,`**（`⌘,`）、选择菜单栏 **ATBCmder ➔ 偏好设置...**，或在语义命令条（`/`）中执行 `cm_Options` 随时呼出。

### 2.1 对话框排布与交互模型

偏好设置对话框采用经典的主从分栏布局，完美兼顾鼠标交互与纯键盘操作：

1. **左侧大类导航列表 (Sidebar)**：固定宽度 195 像素，字体清晰适中（14pt 界面字）。使用键盘方向键 `↑` 与 `↓` 即可快速轮转分类，或者直接鼠标点击。
2. **右侧滚动内容页 (Page Scroll Area)**：无边框平滑滚动容器 (`QScrollArea`)。当在左侧切换分类时，右侧对应的内容页平滑就位，绝无窗口尺寸跳动或屏幕闪烁。
3. **底部操作控制条**：
   - **确定 (OK)**：全面校验所有分类页的输入合法性，将改动原子化写入磁盘 (`atbcmder.xml`)，触发多语言翻译与主题刷新，并关闭对话框。
   - **应用 (Apply)**：无需关闭弹窗即可将改动即时生效。这在实时预览不同界面字体、主题深浅色微调、测试列宽填充系数或自动刷新灵敏度时格外好用。
   - **取消 (Cancel)**：丢弃本轮所有未应用的修改；若刚才临时预览过主题，系统会自动回滚至进入设置前的原始外观。

### 2.3 实时外观主题与免重启多语言切换

不同于老旧软件修改界面外观后必须重启的落后体验，ATBCmder 实现了 **热插拔主题渲染与动态国际化**：

1. **外观主题实时预览**：打开 **常规** 分类页，在 `经典 (Classic)`、`浅色 (Light)`、`深色 (Dark)` 与 `macOS 原生精致风格 (Stylish)` 之间任意切换，主界面窗口会即刻通过 Qt 样式表引擎重新着色渲染。若点击 **取消**，界面会瞬间无损还原回修改前的原始配色。

### 3.1 作用域隔离机制 (Context Scoping)

为了避免快捷键在不同工作场景下相互争抢，ATBCmder 将按键监听划分为独立的 **上下文作用域 (Context Scopes)**。在一个作用域中绑定的按键不会污染其他无关窗口：

- **Main (全局通用)**：跨越所有子窗口始终有效的基础全局快捷键（如 `Cmd+,` 打开设置、`Cmd+Q` 退出程序）。
- **FilePanel (双文件面板)**：仅当键盘焦点位于左侧或右侧文件列表内时响应（如 `F5` 复制、`Space` 计算目录体积、`Backspace` 返回上一层）。
- **Viewer (全能查看器)**：在 Universal Lister 独立预览窗口 (`F3`) 中生效：控制文本编码、16 进制模式切换 (`2` / Hex Mode)、图片旋转缩放与媒体播放。
- **Editor (代码编辑器)**：在内置文本编辑器 (`F4`) 中生效：控制语法高亮、缩进排版、代码查找替换 (`Cmd+F`) 与即时保存 (`Cmd+S`)。
- **Differ (文件内容对比)**：在左右双栏比对窗口中响应：差异块跳转 (`F7`/`F8`)、行级同步对齐与合并。
- **FindFiles (高级搜索)**：在多条件查找对话框中响应：启动搜索、列表导航与投递到列表面板 (`Feed to Listbox`)。
- **MultiRename (批量重命名)**：在批量改名工具中生效：计数器调整、插入变量标签与执行改名。

### 3.2 双按键槽位架构 (主快捷键与次快捷键)

ATBCmder 支持为每一项核心指令分配 **两组独立的快捷键组合**：

- **主快捷键 (Primary Shortcut)**：契合您的主力肌肉记忆（例如经典 Commander 用户偏好的 `F5`）。
- **次快捷键 (Secondary Shortcut)**：现代备选快捷键（例如 macOS 原生操作习惯的 `Cmd+C`）。

### 4.1 智能列宽自适应引擎：三大运算模式

传统双面板工具常面临两难境地：固定列宽下长文件名被截断成省略号 (`...`)，而按最长名字拉伸又会把“大小”、“修改时间”等字段硬挤出屏幕。ATBCmder 提供了三种各展所长的列宽机制：

1. **固定模式 (`fixed`)**：
   - 彻底关闭自动重新计算。
   - 列宽完全服从您的手动拖拽布局。
   - **分侧记忆**：当您用鼠标拖动表头边框（如调节 `名称` 与 `扩展名` 之间的宽度）时，ATBCmder 会捕捉精确像素值，并分别落盘记录左右两扇面板的独立状态（对应 `atbcmder.xml` 中的 `column_widths_left` 与 `column_widths_right`）。
2. **统计平均模式 (`average` — 官方推荐)**：
   - 算法自动度量当前目录下所有可见文件名的平均字符排版像素宽度 (`QFontMetrics`)。
   - 将平均值乘以您配置的 **扩展系数**（滑块范围 `1.0x` 至 `5.0x`，推荐设为 `1.0x`–`1.25x`），并额外预留 40 像素的图标边距与呼吸空间。
   - **核心优势**：绝大多数常规文件名均能舒展完整阅读，且哪怕目录里出现极个别长达 150 个字符的异常日志文件名，也不会把其他列挤压出屏幕。
3. **最大文本宽度模式 (`max`)**：
   - 快速遍历扫描当前目录，以最长的一项文件名为基准向右扩展列宽，并追加 50 像素的安全边距。
   - 确保目录下 100% 的文件名均完整展开绝不省略，特别适合媒体资源素材库与学术数据归档目录。

> [!TIP]
> **海量文件目录性能优化**：  
> 当一个文件夹内包含数万个条目时，如果逐行测量文本像素会导致界面假死。ATBCmder 内置了智能等距抽样算法 (`_MAX_SAMPLE = 200`)，在超大目录中仅均匀抽取 200 个样本行评估字体指标，将计算开销牢牢压制在 2 毫秒以内，同时自动跳过父目录标记 (`..`)。

### 4.2 文件排序逻辑与细粒度选项

随心定制双面板中文件与文件夹的排列规律：

- **自然数字顺序 (Natural sorting)**：开启后，字符串中的数字会按照数学大小排序：`file1.txt`、`file2.txt`、`file10.txt`（而非传统字典序强行排成 `file1.txt`、`file10.txt`、`file2.txt`）。
- **区分大小写排序**：勾选后，大写字母命名的文件优先排在小写之前；取消勾选则对大小写一视同仁。
- **文件夹排序位置 (Folder sort mode)**：
  - `文件夹置顶 (Folders first)`：目录永远整齐排列在列表最上方。
  - `文件置顶 (Files first)`：文件排列在最上方，文件夹沉降至最底部。
  - `混排 (Mixed)`：文件与文件夹按字母顺序完全混同排列。
- **新建与更新文件位置**：控制当后台新增文件或修改旧文件时，目标条目在列表中的落点位置（`自动排序`、`置于顶端` 或 `置于底部`）。

### 4.3 缩略图网格视图与高性能缓存机制

对于摄影师、视觉设计师与影视剪辑师，ATBCmder 原生提供了 **缩略图网格模式** (`cm_ThumbnailsView`)，用高清晰度图片卡片取代传统表格文本。

![缩略图网格视图](images/thumbnails_grid_view.png)  
*图 7.2：高性能缩略图视图，支持自由调节图片边长与平滑网格间距。*

#### 尺寸调节与动态缩放手势
- **默认卡片边长**：支持在 48 像素至 512 像素之间无级调节（默认 128 像素）。
- **触控板双指捏合缩放**：在 Apple 妙控触控板上，直接使用自然双指捏合手势，或按住 **`Ctrl`** 键滚动鼠标滚轮，即可在列表内实时动态缩放缩略图卡片。

#### 多级双层缓存架构
为 4800 万像素的 RAW 原图或复杂的矢量 SVG 生成缩略图非常消耗 CPU。ATBCmder 构建了双层高性能缓存体系：

1. **内存 LRU 高速缓存**：在 RAM 中常驻 500 张解码好的 `QPixmap` 图像对象，确保在列表上下急速滚动时维持 60 帧满帧丝滑。
2. **磁盘永久缓存**：缓存在用户本地缓存目录中：
   - 本地路径：`~/.cache/atbcmder/thumbnails/`
   - 缓存键采用组合哈希机制生成，融合了文件绝对路径、修改时间戳 (`mtime`)、请求像素边长以及系统缓存版本号：
     $$	ext{Cache Key} = 	ext{SHA256}(	ext{filepath} + 	ext{mtime} + 	ext{size} + 	ext{version})$$
   - 一旦文件在磁盘上被修改，时间戳发生变化，旧缓存立即失效并在后台自动重绘。
3. **多线程并发解码池**：图片生成完全由独立的后台 `QThread` 线程池负责，调用 Pillow (PIL) 或硬件加速的 `QImage` 管道，绝不阻塞主界面操作。

### 5.1 内核事件触发与主动轮询回退

ATBCmder 融合了操作系统原生事件驱动机制与主动轮询机制：

- **内核事件监听 (`watch_file_name_change`)**：挂钩 macOS 原生内核事件流 (`FSEvents` / `kqueue`)，零 CPU 消耗实现纳秒级文件新增、删除与重命名捕获。
- **属性变动监听 (`watch_attributes_change`)**：追踪文件体积扩展、权限标志微调与时间戳更新。
- **主动轮询回退周期 (`attr_poll_interval`)**：支持配置 1 至 60 秒的轮询间隔（默认 5 秒）。  
  *为什么必须有轮询？* 局域网网络共享盘（SMB、CIFS、NFS、SFTP VFS）在外部客户端修改文件时，往往无法向本地操作系统推送原生系统通知。主动轮询机制确保了网络挂载目录永远不会出现数据陈旧。

### 5.2 极致节能与 CPU 保护：后台自动挂起

在 MacBook 电池供电模式下，无休止的文件监听会带来不必要的电量损耗。

- 勾选 **当应用程序处于后台闲置时自动挂起** (`watch_only_foreground`)，只要 ATBCmder 的主窗口失去焦点，所有文件监控线程与轮询定时器立即就地休眠挂起。
- 当您通过触控板切回 ATBCmder 时，面板会在唤醒的瞬间统一执行一次平滑刷新，瞬间追平最新文件状态。

## 8. 配置便携化管理与沙盒隔离测试模式

无论是购置新 Mac 迁移环境、为团队开发机批量下发统一设置，还是将精心调校的键位方案分享给好友，ATBCmder 都能让配置备份与还原变得极其简单。

### 8.1 配置文件存储结构与分工

ATBCmder 将所有用户个性化数据保存为结构规范、清晰易读的标准 XML 文本文件，位于操作系统的官方配置目录中：

- **macOS 标准独立版路径**：  
  `~/Library/Preferences/atbcmder/`
- **macOS App Sandbox 沙盒版路径**：  
  `~/Library/Containers/com.aitobox.atbcmder/Data/Library/Preferences/atbcmder/`
- **Linux / UNIX 标准路径**：  
  `~/.config/atbcmder/`
- **一键直达命令**：  
  运行 **`cm_OpenConfigDirectory`**（或从菜单栏选择 **配置 ➔ 打开配置目录**），当前激活面板会瞬间定位打开该文件夹。

```
~/Library/Preferences/atbcmder/
├── atbcmder.xml          # 核心全局偏好设置、窗口位置尺寸、主题外观、列宽自适应
├── atbcmder_hotkeys.xml  # 用户自定义快捷键映射与覆盖规则
├── favtabs.xml           # 已保存的双面板常用标签页工作区方案
├── hotlist.xml           # 常用目录书签 (Ctrl+D) 层级树
└── history.xml           # 历史浏览足迹、内嵌命令行历史、历史搜索记录
```

---

### 8.2 导出全局便携配置包 (`cm_ExportConfiguration`)

生成包含完整环境的一体化便携备份：

1. 从菜单栏选择 **配置 ➔ 导出配置...**（或运行命令 `cm_ExportConfiguration`）。
2. 选择目标保存文件夹并确认文件名（默认：`atbcmder-config.zip`）。
3. 点击 **保存**。

ATBCmder 会在底层将内存中所有待落盘的改动全部刷新，收集全部配置文件（`atbcmder.xml`、`atbcmder_hotkeys.xml`、`favtabs.xml`、`hotlist.xml` 等），并打包生成高强度压缩的便携 ZIP 归档。

---

### 8.3 导入全局配置包与安全防线 (`cm_ImportConfiguration`)

在新电脑上一键还原配置，或回滚到已知的稳定快照：

1. 从菜单栏选择 **配置 ➔ 导入配置...**（或运行命令 `cm_ImportConfiguration`）。
2. 选取此前导出的 `atbcmder-config.zip` 备份包。
3. 在弹出的安全警告弹窗中确认：
   > 导入配置将完全覆盖当前所有的偏好设置。是否确认继续？
4. 点击 **是**。

ATBCmder 会解压并严密校验所提取的 XML 文件合法性，安全替换磁盘数据，并在不重启软件的情况下，热重载内部 `Config()` 单例，毫秒级刷新两扇文件面板与全局列宽布局。

> [!IMPORTANT]
> **企业级安全防线：路径穿越攻击防护 (Anti-Traversal Protection)**  
> ATBCmder 在导入配置包时会对解压条目实施严苛的安全白名单校验（`zipfile` 净化拦截）。任何包含非法路径分隔符（`/`、`\`）、目录穿越符（`..`）或非 XML 扩展名的恶意篡改条目都会被即刻拒绝解包，绝对保障操作系统的底层安全。

---

### 8.4 沙盒隔离测试模式 (`ATBCmder_test.sh`)

当您开发自定义扩展插件、测试大改动键位映射，或评估测试版功能时，应当保护好日常使用的生产配置文件。

ATBCmder 原生支持通过环境变量 `ATBCMDER_CONFIG_PATH` 将配置目录完整重定向。仓库内自带了隔离测试脚本：

```bash
# 以完全物理隔离的沙盒测试模式启动 ATBCmder：
./scripts/ATBCmder_test.sh
```

#### 隔离测试模式底层运行机理：
1. 自动在本地创建独立的干净临时目录：`tests/.test_config/`。
2. 将出厂基线配置文件从 `src/atbcmder/resources/test_config.xml` 复制到临时路径 `tests/.test_config/atbcmder.xml`。
3. 注入环境变量 `export ATBCMDER_CONFIG_PATH="$(pwd)/tests/.test_config"`。
4. 启动 ATBCmder。在该测试会话中做的任何设置更改或删除，仅作用于临时测试目录，您个人日常使用的 `~/Library/Preferences/atbcmder/` 保持 100% 纤尘不染。

## 9. ⚡ 高手进阶：深度定制实战技巧

### 进阶技巧 1：基于 Chezmoi / Ansible 实现 Dotfile 自动化同步
因为 ATBCmder 将全部运行状态序列化为标准的 UTF-8 XML 文本，您可以毫无阻碍地将其纳入个人 Git Dotfiles 仓库，并使用 Chezmoi 或 Ansible 实现多设备自动化同步：

```bash
# 使用 Chezmoi 管理 ATBCmder 配置文件示例：
chezmoi add ~/Library/Preferences/atbcmder/atbcmder.xml
chezmoi add ~/Library/Preferences/atbcmder/atbcmder_hotkeys.xml
```

### 进阶技巧 2：超大网络挂载盘的性能调优
当挂载拥有数百万文件的企业级大型 SMB/NFS 存储时，频繁的系统事件可能导致局域网通信拥塞：

1. 打开 **偏好设置 ➔ 自动刷新**。
2. 取消勾选 **当大小、修改日期或属性改变时触发**。
3. 将 **轮询回退间隔周期** 调整为 `15` 或 `30` 秒。
4. 把网络挂载根路径（如 `/Volumes/EnterpriseShare`）添加到 **路径黑名单排除列表** 中。
5. 在需要确认最新文件时，使用手动刷新快捷键（**`Ctrl+R`** / `⌘R`）。

### 进阶技巧 3：外部命令环境变量与 Homebrew 路径继承
在为工具栏按钮或文件关联配置自定义外部脚本时，ATBCmder 会完整继承当前用户的 Shell 环境变量（包括 `PATH`、`HOME`、`USER` 等）。您可以直接调用通过 Homebrew 安装在 `/opt/homebrew/bin/` 目录下的各类命令行工具（如 `ffmpeg`、`code`、`git`），无需繁琐书写绝对全路径。

### 进阶技巧 4：浮动元数据提示框的定制与开闭
ATBCmder 内置了半透明磨砂质感的浮动元数据提示卡片，在鼠标悬停时能够呈现图片分辨率、EXIF 拍摄参数、音频码率与压缩包内文件数。您可以在 **偏好设置 ➔ 文件视图** 中根据个人审美偏好自由开启或关闭该提示。

## 10. 系统权限与安全警示

> [!CAUTION]
> **覆盖全局核心按键操作的谨慎提醒**  
> 在 `Main` 或 `FilePanel` 作用域中覆盖主快捷键会立即剥夺原有命令的键位响应。如果不小心将 `F5`（复制）或 `Enter`（打开）等至关重要的基础操作误删，请使用快捷键编辑器底部的 **恢复出厂默认键位** 按钮立即重置。

> [!WARNING]
> **导入配置将全面覆盖现有数据**  
> 通过 `cm_ImportConfiguration` 导入配置包会无条件覆盖当前磁盘上的 `atbcmder.xml`、`favtabs.xml` 与 `hotlist.xml`。在导入来自他人的外部配置包之前，请务必先将自己现有的配置导出一份副本作为安全备份。

> [!IMPORTANT]
> **macOS App Sandbox 与完全磁盘访问权限**  
> 若 ATBCmder 在 macOS App Sandbox 沙盒模式下运行，未经用户明确授权前无法访问沙盒容器之外的本地卷与外接移动硬盘。若在浏览时频繁遭遇权限拒绝告警，请在菜单栏执行 **`cm_GrantFilesystemAccess`** 完成系统完全磁盘访问权限引导。

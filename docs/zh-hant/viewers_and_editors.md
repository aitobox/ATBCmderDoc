# 第 4 章：全能萬用檢視器與內建編輯器

在正統雙面板檔案管理體系中，工作效率在很大程度上取決於**檔案的審視與微調速度**。僅僅為了驗證一個雜湊值、查閱一行配置檔案、裁剪一張截圖或翻看一份 PDF，就不得不啟動龐大笨重的整合開發環境 (IDE) 或外部大型軟體，不僅極大地消耗記憶體，還會造成大量視窗堆疊的認知負擔。

ATBCmder 透過在應用程式核心中直接整合一套多引擎、高效能的**全能檢視與編輯子系統**徹底解決了這一痛點。無論是在左右面板之間巡航時的低延遲無感即時預覽、深入二進位制位元組底層的 Hex 模式、在整理檔案時在後臺靜默播放的音樂播放器，還是具備語法高亮與原子級安全寫入的程式碼編輯器，均可透過純鍵盤瞬時召喚。

## 2. 對側面板快速預覽 (`Cmd+Q` / `Ctrl+Q` / `cm_QuickView`)

**對側快速預覽 (Quick View)** 是雙面板管理器的效率王牌之一。無需頻繁開啟和關閉浮動視窗，當你在一側資料夾中順次翻閱成百上千張檔案時，對側面板會自動變為一個隨游標聯動的沉浸式視口。

![快速檢視面板](images/quick_view_panel.png)  
*圖 4.1：嵌入對側面板的快速預覽檢視，一邊瀏覽目錄一邊實時展現程式碼語法高亮。*

### 2.1 雙面板協同預覽優勢

開啟快速預覽的工作流程：

1. 在當前啟用面板中移動游標選定任意檔案或資料夾。
2. 按下 **`Cmd+Q`**（`⌘Q`）或 **`Ctrl+Q`**（`cm_QuickView`）。
3. 對側閒置面板即刻退出原有的檔案列表，轉變為 **快速預覽容器 (`QuickViewContainer`)**，直接渲染游標所在檔案的真實內容。
4. 再次按下 `Cmd+Q` 或 `Ctrl+Q`，即可一鍵關閉預覽，對側面板瞬間無損恢復原先的分頁與資料夾列表。

### 2.2 100 毫秒防抖動極速巡航

當長按鍵盤 `↑` 或 `↓` 鍵在海量目錄中快速滾動時，普通的預覽元件極易造成主介面嚴重卡頓甚至劇烈的磁碟尋道風暴。

ATBCmder 內建了精密調優的 **100 毫秒單次防抖定時器 (`_quick_view_timer`)**：

- 當游標在行間疾速掠過時，系統僅在記憶體中暫存目標路徑；
- 只有當游標在某個條目上穩定停留超過 100 毫秒時，底層才會觸發檔案讀取、語法樹解析或多媒體解碼；
- 即便翻閱幾千張高畫素 RAW 照片或巨型資料轉儲，列表依然能穩定保持 60+ FPS 的絲滑體驗。

### 2.3 按 `Tab` 鍵實現對稱映像檔翻轉 (Symmetric Focus Flipping)

在許多傳統軟體中，一旦切換面板焦點，原有的預覽就會中斷消失。ATBCmder 首創了**對稱映像檔翻轉引擎**：

- 假設快速預覽正在**右面板**呈現，此時你按下 **`Tab`** 鍵將鍵盤焦點轉移至右側：
  1. 右面板會瞬間退出預覽模式，無縫還原為可互動的檔案表格，供你挑選檔案；
  2. 快速預覽檢視會**自動映像檔切換至左面板**，實時展示右面板游標當前高亮的檔案！
- 無論焦點落在左欄還是右欄，整個瀏覽審閱流程永不中斷。

## 3. 全能檢視器 Lister (`F3` / `Fn+F3` / `cm_View`)

如果說快速預覽旨在實現雙面板內部的高速檢視，那麼**全能檢視器 Universal Lister**（`F3` / `Fn+F3` / `cm_View`）則是為深度分析量身定製的獨立視窗 (`UniversalViewerDialog`)。你可以同時開啟多個檢視器視窗並排對照，甚至拖放到外接雙顯示器上持續監控實時日誌。

### 頂部快捷操作工具欄

檢視器頂部配備了一體化的高效控制條：

```
[文字 (1)] [Hex (2)] [自動換行 (Alt+W)] [顯示行號 (Alt+L)] [實時追蹤 (F5)] | [◀ 上一個 (P)] [下一個 ▶ (N)] | [🔍 查詢 (Ctrl+F)] [跳轉到行 (Ctrl+G)] | [系統開啟 (Ctrl+O)] [全屏 (F11)]
```

- **文字模式 (`1`) / 十六進位制模式 (`2`)**：瞬間在解碼字元與原始位元組檢視之間切換。
- **自動換行 (`Alt+W` / `⌥W`)**：針對超長行開啟軟換行。
- **顯示行號 (`Alt+L` / `⌥L`)**：切換左側行號基準線。
- **實時日誌追蹤 (`F5`)**：動態捕獲並自動滾動到底部顯示新寫入的日誌內容。
- **上一個檔案 (`P`) / 下一個檔案 (`N`)**：無需關閉視窗，直接切換檢視同目錄下的相鄰檔案。
- **查詢內容 (`Ctrl+F` / `Cmd+F`)**：彈出底部停靠的高階搜尋欄。
- **跳轉到行 (`Ctrl+G` / `Cmd+G`)**：輸入行號瞬間直達。
- **在系統中開啟 (`Ctrl+O` / `Cmd+O`)**：一鍵將當前檔案交付給 macOS 系統預設程式（如預覽、Safari 或 Xcode）處理。
- **全屏瀏覽 (`F11` / `Alt+Enter`)**：鋪滿整個螢幕進入沉浸模式。

### 3.1 領域 1：辦公文件與結構化書籍

ATBCmder 內建了強大的文件解析核心，無需等待笨重的 Office 辦公套件漫長啟動。

#### 3.1.1 Word 與富文字文件 (`DocumentPanel`)
按下 `F3` 檢視 Word (`.docx`, `.doc`)、富文字 (`.rtf`) 或 OpenDocument (`.odt`) 檔案：

- **卡片式頁面排版**：採用居中陰影卡片模式 (`.doc-page`)，邊距與排版嚴格貼合現代字處理排版標準。
- **格式完好保留**：完整保留段落標題層級、加粗/斜體/下劃線、顏色微調、無序與有序列表，以及可點選的超連結。
- **多列表格與內嵌圖渲染**：原生支援多列表格排版，自適應單元格間距，並高保真繪製內嵌圖。
- **縮放與全文檢索**：支援平滑縮放（`Ctrl++` / `Ctrl+-`），並透過 `ViewerSearchBar` 在數萬字的長文中進行快速檢索。

#### 3.1.2 簡報幻燈片 (`PresentationPanel`)
針對 PowerPoint 簡報 (`.pptx`, `.ppt`)：

- **幻燈片卡片瀏覽**：每一張幻燈片均被提取為一個帶投影的獨立畫幅卡片 (`.slide-card`)，方便上下逐頁檢閱。
- **幻燈片側邊抽屜**：左側滑動抽屜展示全部幻燈片的微縮索引圖，百頁 PPT 也能一秒直達。
- **內容全文搜尋**：按 `Cmd+F` 可穿透檢索幻燈片標題、正文要點、演講者備註及文字註釋框。

#### 3.1.3 PDF 專業級閱讀器 (`PdfPanel`)
由 `PySide6.QtPdf` 與 `QPdfView` 原生硬核驅動：

![PDF 檢視器](images/pdf_viewer.png)  
*圖 4.2：PDF 閱讀器具備大綱目錄樹、頁面縮圖側邊欄、全文高亮檢索與深色護眼模式。*

- **連續平滑多頁滾動**：支援連續滾動模式 (`QPdfView.PageMode.MultiPage`)，亦可自由切換單頁或雙頁跨頁模式。
- **多功能側邊導航欄**：
  - *目錄大綱樹*：點選 PDF 章節書籤 (`QPdfBookmarkModel`) 瞬間跳轉對應頁碼。
  - *縮圖預覽列表*：透過垂直側邊欄 (`PdfThumbnailList`) 直觀翻閱圖文版式。
- **全文高亮與命中索引**：按 `Cmd+F` 實時檢索，命中的文字全部高亮顯示，並標註序號（如 `第 3 處 / 共 28 處`），支援 `Enter` / `Shift+Enter` 來回穿梭。
- **三大閱讀主題**：
  - *標準模式*：原版白紙黑字呈現。
  - *反色夜間護眼模式*：智慧反轉 RGB 畫素亮度 (`InvertColorEffect`)，夜間閱讀不刺眼。
  - *暖色羊皮紙*：大幅濾除有害藍光，呵護長時間文字閱讀。
- **加密解密與安全屬性**：內建 `PdfPasswordDialog` 優雅支援口令解密，並透過 `PdfPropertiesDialog` 檢視 PDF 作者與生成引擎資訊。

#### 3.1.4 EPUB 電子書閱讀器 (`EpubPanel`)
針對技術手冊、電子教程及書籍 (`.epub`)：

- **雙核架構**：優先採用 `QWebEngineView` 配套 `EpubUrlSchemeHandler` 渲染複雜 CSS 樣式與 SVG 向量排版；在極簡環境下自動平滑降級至 `QTextBrowser`。
- **目錄樹側欄**：透過 `QTreeView` 展開層級章節，單機即閱。
- **字號無級縮放**：底部工具欄滑動條實時縮放閱讀文字大小。
- **多主題適配**：明亮白、暗夜黑與復古淺黃一鍵切換。

#### 3.1.5 Markdown 格式化解析 (`MarkdownPanel`)
針對工程 README、技術備忘與開發規範 (`.md`, `.markdown`)：

- **GitHub 規範支援 (GFM)**：高保真排版各級標題、引用塊、分割線、任務打勾清單 (`- [x]`) 與複雜表格。
- **程式碼塊專屬著色**：對 ```` ```python ````、```` ```bash ```` 等語法塊渲染專屬灰度背景、等寬程式碼字型及邊框。

針對開發者、資料分析師與運維工程師，ATBCmder 提供了一整套免啟動第三方客戶端的離線輕量資料檢視工具。

#### 3.2.1 高效能電子表格 (`SpreadsheetPanel`)
在大型 Office 套件中開啟幾十兆的 CSV 或多工作表 Excel 往往需要耗費十餘秒，而在 ATBCmder 中則是毫秒級瞬開：

![Excel 電子表格與資料預覽](images/xls_viewer.png)  
*全能檢視器中的 Excel 表格流式預覽，支援多工作表標籤欄與行列座標定位*

- **全格式支援**：相容 Excel (`.xlsx`, `.xls`)、逗號分隔符 (`.csv`) 與製表符分隔符 (`.tsv`)。
- **多工作表標籤欄**：包含多個 Sheet 的工作簿會在底部展示原生的 `QTabBar` 標籤，點選自由切換。
- **虛擬表格流式模型 (`VirtualSpreadsheetModel`)**：利用 `canFetchMore` 和 `fetchMore` 實現按需流式懶載入。面對幾十萬行的巨型 CSV 資料，記憶體消耗極低，上下滾動不卡頓。
- **行列座標凍結**：表格頂部的字母列標（`A, B, C...`）與左側的行號（`1, 2, 3...`）始終凍結懸浮定位。
- **剪貼簿 TSV 格式匯出**：框選任意單元格區域按 **`Cmd+C`**（`⌘C`），內容自動以標準 TSV 製表符格式存入剪貼簿，可直接貼上到程式碼、終端機機機或 Slack 中。
- **單元格快速定位**：按 `Cmd+F` 輸入關鍵字，游標瞬移定位到命中行。

#### 3.2.2 SQLite 資料庫極速檢視器 (`SqlitePanel`)
無需開啟外部 Navicat 或 DBeaver，直接穿透檢視 SQLite 庫檔案 (`.sqlite`, `.sqlite3`, `.db`)：

- **表與檢視目錄樹**：左側面板完整列出所有資料表和檢視名，並實時統計行數。點選任意表名即刻在右側載入。
- **虛擬化資料瀏覽**：依託 `VirtualSpreadsheetModel` 順暢翻閱數十萬條海量資料記錄。
- **互動式 SQL 查詢控制檯**：在頂部的 SQL 編輯區輸入自定義語句，按下 **`Ctrl+Enter`**（或 `Cmd+Enter`）即可立即執行並展示結果集。
- **安全資料型別化**：二進位制資料流安全呈現為 `<BLOB: N 位元組>`，空值以斜體 `NULL` 標識，防止亂碼報錯。
- **結果集匯出**：右鍵點選即可將當前查詢資料快速匯出為 CSV 或 TSV 格式。

#### 3.2.3 Jupyter Notebook 離線免服務解析 (`NotebookPanel`)
檢視 Python 資料科學、AI 模型訓練與演算法 Notebook (`.ipynb`)：

- **零服務端純本地離線解析**：完全不需要在本地後臺啟動 Jupyter Server 或 Python 環境。
- **卡片式 Cell 互動排版**：
  - *Markdown Cell*：渲染為清晰易讀的圖文說明。
  - *Code Cell*：帶語法高亮、行號及專屬執行批次角標（如 `[1]`, `[14]`）。
  - *Output 區域*：完美呈現控制檯列印文字、報錯呼叫棧，以及嵌入的 base64 PNG/SVG 資料圖表。

#### 3.2.4 原始碼與長文字流式檢視 (`TextPanel`)
主文字渲染引擎專為極速載入與超大日誌設計：

- **64 KB 分塊安全讀取 (`FileLoaderWorker`)**：以 64 KB 為單位進行塊級流式載入，並智慧對齊換行邊界，杜絕主執行緒凍結與多位元組 UTF-8 截斷亂碼。
- **Pygments 豐富語法著色**：支援超過 150 種程式語言與配置檔案，並隨系統明暗主題自適應色彩。
- **智慧編碼檢測與切換**：整合 `chardet` 字符集探測，並在底部狀態列提供 UTF-8、GB18030、Big5、Shift-JIS、Windows-1252 等一鍵編碼過載。
- **實時日誌追加跟蹤 (`F5`)**：啟用 `FileTailWatcher` 引擎，實時捕獲外界寫入的新日誌並自動滾屏，完美復刻 UNIX `tail -f` 體驗。

#### 3.2.5 原始二進位制 Hex 檢視模式 (`2` / Hex Mode)
在分析可執行二進位制程式、韌體轉儲或損壞的檔案碎片時：

- **16 位元組 Hex 矩陣**：經典三列結構——左側為 8 位十六進位制偏移地址，中間為每行 16 位元組（分成兩組 8 位元組）的十六進位制碼，右側為可見 ASCII 對映（不可見字元用 `.` 標識）。
- **零位元組自動 Hex 探測**：若在檔案開頭的 1 KB 內部探測到了空位元組 ` `，ATBCmder 會自動將該檔案切入 Hex 模式開啟，避免終端機機機或文字引擎亂碼。

## 4. 雙模內建編輯器架構 (`F4` / `Fn+F4` / `cm_Edit`)

ATBCmder 內建了一套極為聰慧的 **雙模編輯器分發路由引擎**：

- **當游標停留在文字、程式碼或配置檔案上時**：按下 `F4` 會開啟原生的 **內建程式碼編輯器 (`EditorWindow`)**；
- **當游標停留在圖片檔案（`.png`, `.jpg`, `.webp`, `.bmp`, `.svg`）上時**：按下 `F4` 會**全自動啟動專業級影象標註編輯器 (`ImageEditorDialog`)**！

若要在當前面板目錄下憑空新建並編輯一個檔案，只需按下 **`Shift+F4`**（`cm_EditNew`）。系統會彈出名稱輸入框（如輸入 `deploy.sh` 或 `docker-compose.yml`），新建完成後自動直接載入編輯器。

```

├────────────────────────────────────────────────────────────────────────────────────────┤
│  [💾 儲存] [另存為] | [↶ 撤銷] [↷ 重做] | [🔍 查詢] [替換] | [自動換行] [行號] [縮放]  │
├──────┬─────────────────────────────────────────────────────────────────────────────────┤
│ 0001 │ #!/usr/bin/env bash                                                             │

│ 0004 │ echo "正在部署 ATBCmder 發行包..."                                              │
│ 0005 │ TARGET_DIR="/opt/atbcmder"                                                      │
│ 0006 │ if [ ! -d "$TARGET_DIR" ]; then                                                 │

├──────┴─────────────────────────────────────────────────────────────────────────────────┤

├────────────────────────────────────────────────────────────────────────────────────────┤

└────────────────────────────────────────────────────────────────────────────────────────┘
```

#### 核心程式碼編輯能力
- **Pygments 豐富語法高亮**：支援 150 餘種程式語言與配置檔案，自動根據字尾與檔案第一行 Shebang 識別語言型別。
- **動態等寬行號槽**：左側行號欄隨文件總行數自動擴充套件寬度並嚴格垂直居中對齊。
- **智慧縮排與程式碼塊縮排**：按下 `Enter` 換行自動繼承上一行縮排級別；框選程式碼塊按 `Tab` 統一向右縮排，按 `Shift+Tab` 統一向左縮排。
- **軟自動折行 (`Alt+W` / `⌥W`)**：在遇到單行超長文字時按視窗邊界折行，絕不在物理檔案中插入虛假換行符。
- **字號隨心縮放**：使用 `Cmd++` (`⌘+`)、`Cmd+-` (`⌘-`) 自由放大縮小字號，按 `Cmd+0` (`⌘0`) 一鍵復位。

#### 互動式查詢與替換控制欄 (`EditorReplaceBar`)
按下 **`Cmd+F`**（`⌘F`）或 **`Cmd+Option+F`**（`⌥⌘F`）撥出底部停靠的替換面板：

- 實時遞增式搜尋與序號標記（如 `第 4 處 / 共 19 處`）。
- 搜尋選項開關：區分大小寫 (`[Aa]`)、全詞匹配 (`[]`) 與 Python 正規表示式 (`[.*]`)。
- 批次替換支援：支援對當前匹配項執行 **替換**，或一鍵執行 **全部替換**。

#### 狀態列資訊與原子級安全儲存
- **遙測資料**：實時展示當前行列、字元數、字元編碼（UTF-8等）以及換行符規範（`LF` 還是 `CRLF`）。
- **未儲存髒狀態提示**：一旦有未儲存的修改，標題欄與狀態列會醒目呈現 `*` 標識。
- **原子級安全儲存 (Atomic Save)**：按下 `Cmd+S` 時，ATBCmder 會先將資料寫入同一分割槽的臨時檔案中，落盤刷盤並確認無損後，再透過原子系統呼叫覆蓋原檔案，徹底防止儲存中途斷電或崩潰導致檔案被截斷為空檔案。

- **單項自由水印 (`single`)**：單行文字或單張 Logo，支援滑動條調節不透明度。

### 4.3 無縫跨 VFS 遠端與壓縮包編輯 (Round-Trip Editing)

ATBCmder 編輯器最驚豔之處在於其與 **虛擬檔案系統 (VFS)** 的原生無縫回寫：

- 無論你是在遠端 SFTP 伺服器上的 Shell 腳本上按 `F4`、在 Nextcloud WebDAV 共享上的配置檔案上按 `F4`，還是在本地一個多層巢狀的 `.zip` 壓縮包內部的截圖上按 `F4`：
  1. ATBCmder 會在後臺把目標檔案提取到本地安全的隔離沙盒暫存區；
  2. 自動載入 `EditorWindow` 或 `ImageEditorDialog`；
  3. 當你按下 `Cmd+S` 儲存時，ATBCmder 會自動攔截儲存動作，並**全自動將更新後的資料流回寫上傳至遠端 SFTP/SMB，或喚起 `RepackWorker` 重打包該壓縮包**！
  4. 編輯器關閉後，本地臨時快取徹底乾淨清除。使用者完全不需要經歷“手動解壓 ➔ 修改 ➔ 重新壓縮 ➔ 覆蓋上傳”的痛苦流程。

## 5. ⚡ 進階技巧與深度解析

### 技巧 1：在面板中按 `F3` 動態追加背景音樂

當音訊播放器已經在**後臺模式**下執行播放時：

1. 在左右任意檔案面板中，選中一首或多首新的音訊檔案；
2. 直接按下 **`F3`**（或 `Fn+F3`）；
3. ATBCmder 檢測到後臺已有常駐播放器例項，會自動把選中的曲目**直接追加到當前播放列表末尾 (`append_tracks`)**，完全不會中斷當前正在播放的旋律！

### 技巧 2：自定義檔案型別關聯與啟動宏 (`cm_FileAssoc`)

預設情況下，按 `F3` 開啟內建檢視器，按 `F4` 開啟內建編輯器。如果某些特殊格式你想呼叫外部專業工具開啟，可利用 **檔案關聯管理器 (`cm_FileAssoc`)**：

前往選單欄 **配置 ➔ 檔案關聯配置...**：

- 可以將指定的副檔名規則（如 `*.rs`, `*.py`, `*.psd`）與外部命令繫結。
- **內建指令**：可對映為內部 Commander 命令（如 `cm_View`, `cm_Edit`）。
- **外部 Shell 命令與宏變數替換**：
  - `%f` ➔ 替換為所選檔案的完整絕對路徑（如 `/Users/brain/main.rs`）。
  - `%d` ➔ 替換為所選檔案所在的父級目錄（如 `/Users/brain`）。
  - `%n` ➔ 替換為無字尾的純檔名（如 `main`）。
  - `%e` ➔ 替換為純副檔名（如 `rs`）。

*例如為 Rust 程式碼檔案關聯 VS Code 開啟：*
```bash
code --goto %f
```

### 技巧 3：實時日誌流追蹤模式 (`F5`)

在除錯本地服務、Docker 容器日誌或系統後臺程序時，在 Universal Lister (`F3`) 中開啟該日誌檔案並按 **`F5`**：

- 啟動 `FileTailWatcher` 監聽；
- 檢視器會自動滾動到底部並實時將新寫入的每一行日誌列印到屏上，完全媲美 UNIX `tail -f`；
- 在追蹤的同時可以保持 `Cmd+F` 搜尋過濾，新進來的錯誤行依然會實時高亮。

### 技巧 4：幾十 GB 超巨型檔案的直接偏移量二進位制檢視

面對 20 GB 以上的巨大資料庫 Dump 或物理磁碟映像檔，千萬不要嘗試用常規文字編輯器開啟。在 ATBCmder 的全能檢視器中：

- 使用 **跳轉到行 (`Ctrl+G`)** 或底部滑塊；
- 底層的 `FileLoaderWorker` 會直接呼叫系統檔案控制代碼的二進位制定位 (`fh.seek(offset)`)，每次僅僅讀取並渲染當前視口所需的 64 KB 資料塊；
- 哪怕審閱數 TB 的超大映像檔，記憶體佔用也是常數級的幾十 MB，毫秒級即點即達。

## 6. 步驟化實用實戰流程

### 實戰 1：快速審閱並對敏感截圖進行脫敏打碼

**場景目標**：你擷取了一張包含內部 API 金鑰和客戶手機號的配置介面截圖，需要在提交到公網工單系統前進行安全脫敏並裁剪。

```
第 1 步：在啟用面板選中 screenshot.png，按下 F4 開啟影象編輯器。
第 2 步：在左側工具欄中選擇“馬賽克 / 模糊”工具。
第 3 步：用滑鼠拖拽框選住包含 API 金鑰與電話號碼的文字區域，文字瞬間被模糊打碼。
第 4 步：選擇“裁剪”工具，框選出核心視窗區域，按下 Enter 確認裁剪。
第 5 步：按下 Cmd+S (儲存) 直接覆蓋原圖，或選擇“另存為”儲存為 screenshot_redacted.png。
第 6 步：按 Esc 退出編輯器，面板中的圖片已完好就緒。
```

---

### 實戰 2：實時追蹤日誌並在 Hex 模式下定位編碼異常字元

**場景目標**：某個後臺資料寫入程序莫名報錯崩潰，疑似寫入了非法的多位元組字元，需要實時抓取並在底層二進位制層面確診。

```
第 1 步：在面板選中 server.log，按 F3 開啟全能檢視器。
第 2 步：按下 F5 開啟實時追蹤模式 (Tail Mode)，觀察螢幕下方滾動的實時日誌。
第 3 步：報錯資訊刷出瞬間，再次按 F5 暫停滾屏。
第 4 步：按下 Cmd+F 輸入報錯特徵字串進行定位。
第 5 步：按下鍵盤數字鍵 2 瞬間切入 Hex 十六進位制檢視模式。
第 6 步：在右側的 16 位元組十六進位制列中精準審查不可見控制字元的具體位元組碼。
第 7 步：按下鍵盤數字鍵 1 恢復格式化文字顯示，按 Esc 退出。
```

### 實戰 3：極速新建程式碼腳本並賦予可執行許可權

**場景目標**：在當前工程中迅速新建一個用於構建釋出的自動化腳本，新增標準 Bash 頭部並完成許可權設定。

```
第 1 步：在當前面板按下 Shift+F4 (cm_EditNew)。
第 2 步：在彈出框中鍵入 build_release.sh 並按回車。
第 3 步：內建程式碼編輯器立即開啟，游標就緒。
第 4 步：編寫指令碼內容（系統自動完成縮排繼承）：
         #!/usr/bin/env bash
         set -euo pipefail
         echo "開始編譯專案二進位制..."
第 5 步：按下 Cmd+S (⌘S) 原子安全寫入磁碟。
第 6 步：按下 Cmd+W (⌘W) 關閉編輯器。
第 7 步：在面板中選中 build_release.sh，按下 Alt+Enter (cm_SetFileProperties)。
第 8 步：勾選所有者的“執行”許可權 (chmod +x) 並按回車儲存。
```

## 7. 安全與系統重要警示

> [!WARNING]
> **外部協同修改檔案衝突預警**  
> 如果在內建編輯器 (`F4`) 開啟編輯某個檔案的同時，該檔案被外部其他程式修改或清空，ATBCmder 會在儲存時彈出警示彈窗。建議選擇 **重新載入 (Reload)** 審閱磁碟上的最新版本，或選擇 **另存為** 將本地修改儲存在新副本中，切勿盲目覆蓋。

> [!IMPORTANT]
> **未知二進位制檔案安全：純文字 vs Hex 模式**  
> 如果把一個未知格式的可執行程式或壓縮包強行以純文字模式開啟並儲存，UTF-8 解碼過程中產生的替換字元 (`\ufffd`) 會徹底摧毀原檔案的底層結構。ATBCmder 的全能檢視器 (`F3`) 預設處於嚴格只讀狀態，確保在審閱時絕不會意外破壞二進位制檔案。

> [!CAUTION]
> **針對網路慢速共享上的快速預覽建議**  
> 在透過高延遲或弱網環境連線的遠端伺服器（如跨洋 FTP/SFTP）上，開啟快速預覽 (`Cmd+Q`) 會在翻閱時頻繁向遠端發起資料塊流式拉取。若網路頻寬有限，建議按 `Cmd+Q` 暫時關閉快速預覽，以保持純目錄翻閱的極速響應。

> [!TIP]
> **Mac 鍵盤功能鍵操作習慣**  
> 在現代 MacBook 或 Magic Keyboard 上，頂排功能鍵預設用於控制音量與亮度。觸發 `F3` 或 `F4` 時，請配合按住左下角的 **`Fn`** 鍵（即按 `Fn+F3`、`Fn+F4`）。或者前往 macOS **系統設定 ➔ 鍵盤 ➔ 鍵盤快速鍵... ➔ 功能鍵**，開啟“將 F1、F2 等鍵用作標準功能鍵”。

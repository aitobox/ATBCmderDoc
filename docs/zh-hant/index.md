## 雙面板的核心哲學

傳統的單視窗檔案管理器（如 macOS 自帶的Finder / Finder）常常讓使用者陷入在多個重疊視窗之間來回切換的困境：不僅容易迷失來源和目標資料夾，還容易誤把檔案拖進錯誤的深層目錄。

```
傳統單視窗瀏覽 (Finder 訪達):
┌────────────────────────┐      ┌────────────────────────┐
│ 資料夾 A (剛才是哪來著?)│ ──?  │ 資料夾 B (要移去哪?)   │  → 視窗層疊雜亂，容易丟失焦點，
└────────────────────────┘      └────────────────────────┘    頻繁發生滑鼠誤拖曳

ATBCmder 正統雙面板互動 (Orthodox Dual-Panel):
┌───────────────────────────────┬───────────────────────────────┐
│       當前作用面板 (來源目錄) │       對側閒置面板 (目標目錄) │
│  當前待操作的檔案清單         │  清晰明確的目標存放位置       │
│  [ 複製 / 移動 / 比對 / 同步  ═════════════════════════════► ]│
└───────────────────────────────┴───────────────────────────────┘
```

ATBCmder 透過經典的 **“源 - 目標 (Source-Target) 雙面板模型”** 徹底解決上述痛點：

- **視野永遠清晰**：左右兩個獨立的目錄檢視並排常駐，無需反覆層疊視窗。
- **方向明確無歧義**：按下複製 (`F5`) 或移動 (`F6`) 時，檔案始終從**當前面板**流向**對側面板**。無需小心翼翼用滑鼠拖曳，絕不會誤拖入臨近的資料夾。
- **手指不離鍵盤的高速操作**：無需頻繁摸滑鼠，按鍵盤方向鍵跳轉目錄、按萬用字元批次標記、秒級回車進入壓縮包、毫秒級執行批次重新命名。
- **告別視窗堆積**：一個視窗容納所有操作——本地全盤、遠端伺服器（FTP、SFTP、SMB、WebDAV）、壓縮包內虛擬瀏覽（`.zip`、`.7z`、`.tar`）以及後臺傳輸佇列全在一處掌控。

### 核心介面功能分割槽詳解

1. **選單欄與 macOS 原生整合 (`[1]`)**：完整遵循 macOS 選單規範，支援標準快速鍵（`⌘,` 開啟偏好設定、`⌘Q` 退出、`⌘W` 關閉分頁），並涵蓋了 Commander 底層的所有功能指令（`cm_*`）。
2. **主工具欄與快速啟動區 (`[2]`)**：提供一鍵直達核心工具的快捷按鈕，包括全域性搜尋 (`Alt+F7`)、後臺操作佇列面板 (`cm_OperationsPanel`)、偏好設定 (`Cmd+,`) 以及快速磁碟機代號切換條。
3. **可互動路徑麵包屑欄 (`[3]`)**：直觀展示當前層級，點選任意中間節點即可秒級向上跳級；點選節點右側下拉小三角，可直接展開同級子目錄。
4. **資料夾分頁與工作區 (`[4]`)**：每個面板均支援新建無限分頁 (`Cmd+T`)、快速關閉 (`Cmd+W`)、鎖定常用路徑，更可將左右兩側佈局完整儲存為常用工作區 (`cm_SaveFavoriteTabs`)。
5. **雙檔案資料面板 (`[5]`)**：左右兩組完全獨立的檔案列表。當前啟用面板具有醒目的高亮邊框和聚焦游標，按 `Tab` 鍵即可在左右面板之間無縫瞬間切換。
6. **垂直居中工具欄與可拖曳分割條 (`[6]`)**：鑲嵌在左右面板正中間的快捷操作豎條。提供滑鼠一鍵觸發 檢視 (`F3`)、編輯 (`F4`)、複製 (`F5`)、移動 (`F6`)、新建目錄 (`F7`)、刪除 (`F8`)、粉碎抹除以及面板互換 (`cm_Exchange`)。按住分割線左右拖曳即可自定義面板寬度比例。
7. **狀態列與磁碟容量指示器 (`[7]`)**：實時統計當前目錄檔案總數、選中項數量、合併位元組大小，並整合生動的磁碟剩餘可用空間進度條。

## 快速指引：選擇適合您的學習路線

無論您是剛接觸雙面板檔案管理器的初學者，還是已有十餘年 Total Commander 使用經驗的老手，ATBCmder 都能讓您得心應手：

### 🟢 路線 A：雙面板新手入門？
*歡迎體驗更高效、更清爽的 macOS 檔案管理新方式！*

如果您此前一直使用Finder (Finder) 或常規桌面檔案瀏覽器，正統雙面板管理器最初可能會讓人有些新奇。一旦掌握了核心模式，您將徹底告別在多視窗間混亂拖動檔案的低效體驗：

1. **從核心概念起步**：閱讀 [第 1 章：新手起步與 macOS 設定](getting_started.md)，瞭解當前啟用面板與對側面板的關係、中間工具欄用法，以及為軟體授予 macOS 完全磁碟訪問許可權。
2. **掌握高頻日常操作**：在 [第 3 章：日常檔案操作與後臺佇列](file_operations.md) 中，學習如何不碰滑鼠快速完成複製、移動、改名和刪除。
3. **極速預覽各類檔案**：在 [第 4 章：全能檢視器與內建編輯器](viewers_and_editors.md) 中，瞭解如何按一下按鍵秒開圖片、聽音訊、讀程式碼和翻閱 PDF。
4. **跟隨實戰場景手冊**：檢視日常備份、NAS 掛載等真實圖文教學，盡在 [第 9 章：實戰場景指南與疑難解答](faq_howtos.md)。

---

### ⚡ 路線 B：Total Commander / Double Commander 資深玩家？
*您所熟悉的一切強大功能與肌肉記憶，專為 macOS 原生打造。*

ATBCmder 專為在現代 macOS 上重塑純正 Commander 體驗而生，無需執行沉重的 Wine 模擬層或老舊的 X11 移植：

1. **查閱雙矩陣快速鍵對映**：在 [第 8 章：快速鍵速查掌中寶](keyboard_shortcuts.md) 中對比熟悉的經典 `F1-F12` 鍵位與 macOS `⌘ Command` 組合鍵對照。
2. **探索高階高階工具**：在 [第 5 章：進階工具與自動化](power_tools.md) 中深入使用多重重新命名 (`Ctrl+M`)、雙欄差異比對 (`Meta+Shift+F12`)、目錄同步 (`Shift+F12`) 和高階搜尋。
3. **連線遠端與虛擬檔案系統**：在 [第 6 章：虛擬檔案系統與網路](network_and_vfs.md) 中體驗對 `.zip`、`.tar` 壓縮包的免解壓原地編輯與實時重打包回寫，以及 SFTP、SMB、WebDAV 穩定掛載。
4. **匯入匯出便攜化配置**：在 [第 7 章：偏好設定與個性化定製](preferences_and_customization.md) 中定製熱鍵、微調核心級 FSEvents 自動重新整理，並實現配置跨裝置無縫遷移。

### 🧭 [第 2 章：導航、分頁與檢視模式](navigation_and_tabs.md)
利用互動式路徑麵包屑層級跳轉、鍵盤快速跳躍 (`Ctrl+\`, `Backspace`)、多分頁高效組織 (`Cmd+T`, `Cmd+W`)、雙面板常用工作區儲存 (`cm_SaveFavoriteTabs`)、常用目錄書籤 (`Ctrl+D`)，以及多種檢視（簡要、詳細、縮圖、樹狀檢視與扁平平鋪檢視 `Cmd+B`）。

### 📁 [第 3 章：日常檔案操作與後臺佇列](file_operations.md)
高效穩健的檔案管理：複製 (`F5`)、移動 (`F6`)、新建資料夾 (`F7`)、刪除入廢紙簍 (`F8`) 與行內快速改名 (`F2`)。精通萬用字元與屬性批次標記、拖曳修飾鍵聯動、重名衝突解決方案、UNIX 許可權與時間戳調整 (`Alt+Enter`)，以及 3 佇列後臺工作管理員 (`cm_OperationsPanel`)。

### 👁️ [第 4 章：全能檢視器與內建編輯器](viewers_and_editors.md)
無需等待第三方笨重軟體啟動。使用快速檢視面板 (`Ctrl+Q` / `Cmd+Q`) 實時預覽對側檔案；全能檢視器 (`F3`) 支援 Word 文件、Excel 表格（虛擬載入）、SQLite 資料庫、Jupyter 筆記本、EPUB 電子書、程式碼語法高亮、原始十六進位制 Hex 檢視 (`2`)、PDF 連續翻頁、後臺音訊播放器與硬體加速影片播放；更可使用雙模 `F4` 編輯器輕鬆編輯程式碼與標註塗抹圖片。

### ⚡ [第 5 章：進階工具與自動化](power_tools.md)
化繁為簡的專業工具箱：多重重新命名工具 (`Ctrl+M`) 結合佔位符與正規表示式、雙欄直觀文字差異比對 (`Meta+Shift+F12`)、雙向資料夾映象同步 (`Shift+F12`)、高階多條件檔案搜尋 (`Alt+F7`) 並“匯出到列表”、Spotlight 與自然語言語義化搜尋 (`/`)、檔案分卷切片與合併、雜湊校驗（MD5、SHA-256、CRC32）、安全徹底粉碎 (`cm_Wipe`) 以及內建終端機機機 (`Ctrl+J`)。

### 🌐 [第 6 章：虛擬檔案系統與網路](network_and_vfs.md)
透過統一的 `vfs://` URI 體系，像操作本地資料夾一樣暢遊遠端伺服器和壓縮包。無需事先解壓即可直接瀏覽 `.zip`、`.tar`、`.7z`，並在儲存後自動無感重打包；建立高強度加密壓縮包 (`Alt+F5`)；透過網路連線管理器長期穩定管理 FTP、SFTP（SSH 金鑰認證）、WebDAV 及區域網 SMB/Samba 共享。

### ⚙️ [第 7 章：偏好設定與個性化定製](preferences_and_customization.md)

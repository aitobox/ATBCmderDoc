# 第 1 章：基礎概念與 macOS 系統配置

歡迎使用 **ATBCmder**！作為一款專為 macOS 12+ 及 Apple Silicon 晶片（M1/M2/M3/M4，ARM64 架構；目前暫不支援 Intel x86_64 架構）深度定製的原生雙面板檔案管理器，ATBCmder 將正統雙面板的高速操控、全鍵盤流暢切換和極致精確度帶到了 Mac 平臺。

本章將為您詳細拆解雙面板的核心理念，帶您逐一熟悉介面核心功能分割槽，指導您透過內建授權嚮導授予 macOS 沙盒與磁碟取用權限，並提供關鍵的系統配置技巧，助您快速上手。

## 1. 快速入門：雙面板設計哲學

如果您習慣了 macOS 自帶的“Finder (Finder)”，平時很可能會開啟一堆層疊重合的視窗，在凌亂的桌面上把檔案拽來拽去，時刻提防著別把檔案拖進旁邊錯誤的子資料夾。

ATBCmder 採用經受了數十年檢驗的 **正統檔案管理器 (Orthodox File Manager, OFM)** 模式：兩側並排展示兩個完全獨立、互為補充的資料夾面板。

```

│  當前作用面板 (來源目錄)                   對側閒置面板 (目標目錄)              │
│  /Users/username/Downloads                 /Volumes/BackupDrive/Projects        │
├─────────────────────────────────────┬───┬───────────────────────────────────────┤
│  名稱               大小    修改時間│   │  名稱                大小     修改時間│
│  ▸ [..]                     --:--   │ 複│  ▸ [..]                       --:--   │
│  ▸ Project_Assets   <目錄>  昨天    │   │  ▸ 2025_Archive      <目錄>   5月12日 │
│  ● release_notes.md 14.2 KB 今天    │ 製│  ▸ Website_V2        <目錄>   8月28日 │

└─────────────────────────────────────┴───┴───────────────────────────────────────┘
```

### 當前啟用面板（源）與 對側閒置面板（目標）

在 ATBCmder 中，所有操作的流向一目瞭然，絕無模糊：

1. **當前啟用面板 (Active / Source)**：
   - 當前鍵盤焦點和游標所在的面板。
   - 您進行的選擇、移動游標、重新命名或檢視，都會直接針對該面板進行。
   - **視覺提示**：當前面板擁有醒目的高亮聚焦外框（遵循 macOS 主題強調色）、分頁高亮文字，以及選中條目上的高亮游標。

2. **對側閒置面板 (Inactive / Target)**：
   - 位於另一側的面板。它始終常駐在螢幕上，展示著另一個獨立的目錄層級。
   - 當您在啟用面板中發起檔案複製或移動時，對側面板就是**預設的目標位置**。
   - **視覺提示**：對側面板邊框柔和暗淡，未獲得焦點，文字對比度適度調低。

### 操作方向準則：永遠從“源”到“目標”

在 ATBCmder 中觸發操作時，應用會自動理清流向：

- **複製 (`F5` / `Cmd+C` ➔ `Cmd+V`)**：將當前啟用面板選中的檔案，直接複製到對側閒置面板正在展示的目錄中。
- **移動 (`F6` / `Cmd+C` ➔ `Opt+Cmd+V`)**：將當前啟用面板選中的檔案移動到對側面板，無需繁瑣輸入或尋找目標路徑。
- **資料夾同步 (`Shift+F12` / `cm_SyncDirs`)**：直接比對左右兩側目錄的異同。

> [!TIP]
> **無需滑鼠小心翼翼拖曳**：在當前面板選中需要處理的檔案，輕按 `F5`（複製）或 `F6`（移動），敲擊 `Enter` 回車確認，傳輸立即開始。

### [1] macOS 原生頂部選單欄
完全融入 macOS 系統頂欄。各項功能、顯示開關、高階工具與設定項劃分清晰：

- **檔案 (File)**：新建分頁、關閉分頁、屬性詳情、沙盒檔案系統授權、退出。
- **選擇 (Mark)**：萬用字元選擇組 (`Num+`)、取消選擇組 (`Num-`)、反選 (`Num*`)、全選 (`Cmd+A`)。
- **命令 (Commands)**：常用目錄書籤 (`Ctrl+D`)、左/右驅動器列表 (`Alt+F1/F2`)、全域性搜尋 (`Alt+F7`)、資料夾同步 (`Shift+F12`)、左右互換 (`Ctrl+U`)、調出終端機機機機 (`Ctrl+J`)。
- **顯示 (Show)**：多檢視模式切換（簡要、詳細、縮圖、樹狀、平鋪扁平檢視）、工具欄顯隱、水平雙面板切換。
- **配置 (Configuration)**：偏好設定 (`Cmd+,`)、儲存當前視窗位置與比例 (`cm_ConfigSavePos`)、儲存分頁組。

### [2] 頂部主工具欄
緊貼視窗標題欄下方，提供一鍵直達的高頻指令：

- **預設按鈕組**：重新整理 (`Ctrl+R`)、對側快速預覽 (`Ctrl+Q`)、複製 (`F5`)、移動 (`F6`)、新建資料夾 (`F7`)、刪除 (`F8`)、搜尋 (`Alt+F7`) 以及偏好設定 (`Cmd+,`)。
- **個性化定製**：在選單欄 **顯示** → **顯示工具欄** 中可隨時開啟或隱藏工具欄以獲取更大瀏覽視野；更可在偏好設定中自由調整圖示尺寸（16px 到 48px）及文字標籤。

### [3] Finder風格可互動路徑麵包屑欄
位於兩側面板頂部，讓層級穿透與跳轉輕而易舉：

- **層級點選跳級**：點選麵包屑中的任意祖先資料夾（例如 `/Users/username/Projects/ATBCmder` 中的 `username`），即可直接回退到該層。
- **子目錄下拉速選**：滑鼠懸停或點選兩級之間的分隔箭頭，即可彈出同級子資料夾下拉選單快速進入。
- **右鍵上下文選單**：右鍵點選任意路徑節點：
  - **在新分頁中開啟**：保留當前面板，並在新標籤中展開該上級目錄。
  - **在Finder中顯示**：呼叫系統 Finder 揭示定位該資料夾 (`open -R`)。
  - **複製路徑**：一鍵將該節點的絕對 UNIX 路徑複製至剪貼簿。
  - **在終端機機機機中開啟**：直接在系統終端機機機機中以此目錄作為工作路徑啟動 (`open -a Terminal`)。
- **位址列直接編輯模式 (`BreadcrumbLineEdit`)**：雙擊麵包屑欄右側的空白區域，路徑條將瞬間轉換為文字輸入框。您可直接貼上或輸入任意路徑（例如 `/var/log`、`~/Library` 或 `vfs://` 壓縮包虛擬路徑），按回車立即直達，按 `Esc` 退出。

### [4] 資料夾分頁欄
兩側面板均擁有各自獨立的分頁體系：

- 使用 `Cmd+T` (`cm_NewTab`) 新建分頁，使用 `Cmd+W` (`cm_CloseTab`) 隨手關閉。
- 滑鼠拖曳分頁可自由調整排布順序。
- 右鍵點選分頁可執行鎖定路徑、重新命名標籤標題、關閉重複標籤，或複製當前標籤至對側面板。

### [5] 雙檔案列表面板
高效能虛擬化列表渲染引擎，即使面對包含數十萬條檔案的巨型目錄也能秒開滾動，絕無拖慢與卡頓：

- 自由排序：點選任意列標題（名稱、型別、大小、修改日期、許可權屬性）即可按升序或降序實時重排。
- 多種檢視模式：詳細多列列表、簡要緊湊網格、縮圖畫廊檢視、樹狀導航檢視以及跨層級平鋪展開的扁平檢視 (`Cmd+B`)。

### [6] 垂直居中工具欄與可拖曳分割條
鑲嵌在左右面板正中間的垂直操作條是 ATBCmder 的標誌性特性之一，將一鍵快捷操作與靈活比例調節完美融合：

![居中工具欄](images/middle_toolbar.png)

- **垂直快捷操作條**：匯聚日常高頻檔案操作按鈕：
  - `cm_Copy`（複製）
  - `cm_Move`（移動 / 剪下）
  - `cm_Delete`（刪除至廢紙簍）
  - `cm_MkDir`（新建資料夾）
  - `cm_Rename`（行內快速改名）
  - `cm_View`（全能檢視器）
  - `cm_Edit`（程式碼/文字編輯器）
  - `cm_Exchange`（對調左右面板路徑）
  - `cm_SyncDirs`（資料夾雙向同步）
  - `cm_FileSearch`（多功能高階搜尋）
- **平滑拖曳分割**：將滑鼠指標移至中間欄邊緣，指標自動變為左右分欄調節箭頭 (`SplitHCursor`)。按住並左右拖曳即可隨意微調兩側面板的寬度配比。
- **Stylish 現代主題一鍵預設**：在選用 Stylish 現代主題時，中間條整合有膠囊分段按鈕，支援一鍵吸附至 **50/50**（等寬）、**70/30**（主面板突出）或 **30/70**（對側面板突出）。
- **個性化設定**：可在 **偏好設定** (`Cmd+,`) → **工具欄** → **中間工具欄** 中隨心開啟或關閉中間工具欄、縮放按鈕尺寸，或在現代扁平與復古立體樣式間自由切換。

### [7] 狀態列與磁碟容量指示器
常駐在視窗最底端：

- **實時統計指標**：顯示當前啟用面板中的檔案與資料夾總數、目錄總容量、已選中項數量及已選合併位元組大小。
- **磁碟容量柱狀條**：直觀展示當前掛載磁碟的卷名稱（如 `Macintosh HD`）、總容量、已用空間以及剩餘可用空間的生動百分比示意條。

## 3. 實戰配置：macOS 沙盒安全機制與全盤檔案授權

現代 macOS 引入了嚴苛的 App Sandbox 應用沙盒隔離機制，以防止流氓軟體非法侵入使用者資料。在執行 ATBCmder（特別是從 Mac App Store 下載安裝或啟用了沙盒編譯的版本）時，應用預設被隔離在受限的獨立容器目錄中：
`~/Library/Containers/com.aitobox.atbcmder/Data`

預設狀態下，沙盒應用無法隨意遍歷或修改容器外部的檔案，除非使用者透過 Apple 原生的安全檔案選擇面板明確授權。

ATBCmder 內建了 **安全範圍書籤 (Security-Scoped Bookmarks)** 技術，讓您只需一次性授權，即可在日後所有使用過程中持久、自由地訪問全盤檔案。

### 認識“安全範圍書籤 (Security-Scoped Bookmarks)”

當您透過 macOS 原生 `NSOpenPanel` 選中並確認某個資料夾時：

1. macOS 系統將簽發一份加密的 **安全範圍書籤**（Security-Scoped Bookmark）。
2. ATBCmder 會將該憑據儲存在本地配置目錄中：
   `~/Library/Application Support/ATBCmder/sandbox_bookmarks.plist`
3. 每次啟動應用時，ATBCmder 會自動載入並啟用這些書籤憑據。
4. 一旦授權成功，您以後再也無需重複確認這些目錄。

### 手把手授權嚮導：使用 `cm_GrantFilesystemAccess`

在首次啟動應用或任何需要的時候，按照以下步驟完成配置：

#### 第 1 步：喚出授權嚮導視窗
在頂部選單欄中，點選 **檔案**（或 **幫助**）→ **授予檔案系統取用權限…**，或執行內部指令 `cm_GrantFilesystemAccess`，彈出授權對話方塊：

```
┌─────────────────────────────────────────────────────────────┐
│  授予檔案系統訪問許可權                                   [x] │
├─────────────────────────────────────────────────────────────┤
│  本版本 ATBCmder 執行在安全的 macOS 沙盒環境中。為了正常    │
│  管理全盤檔案，需要您的明確授權。                           │
│                                                             │
│  [  授權根目錄 (/) 訪問許可權  ]                              │
│                                                             │
│  [  授權外接磁碟 (/Volumes) 訪問許可權  ]                     │
│                                                             │
│  [  開啟系統“完全磁碟訪問許可權”設定…  ]                      │
│                                                             │
│  根目錄授權用於滿足 App Sandbox 沙盒規範。                  │
│  完全磁碟訪問許可權為 macOS 隱私保護機制所必需。              │
│                                                   [ 完成 ]  │
└─────────────────────────────────────────────────────────────┘
```

#### 第 2 步：授予系統根目錄 (`/`) 取用權限
1. 點選 **“授權根目錄 (/) 取用權限”** 按鈕。
2. ATBCmder 將彈出 macOS 原生的選擇器面板，並預設選中系統主硬碟 `Macintosh HD` (`/`)。
3. 點選右下角 **“授權訪問”**（或“開啟”）。
4. 按鈕隨即更新為 **“根目錄取用權限已授予 ✓”** 並置灰鎖定。
5. **授權效果**：授予根目錄 `/` 訪問權後，會自動覆蓋其下方所有的使用者目錄（包括 `~/Documents`、`~/Downloads`、`~/Desktop`、`~/Projects` 以及 `/Applications` 等），因為安全範圍書籤會自動向下遞迴繼承授權。

#### 第 3 步：授予外接磁碟 (`/Volumes`) 取用權限
1. 點選 **“授權外接磁碟 (/Volumes) 取用權限”** 按鈕。
2. 在彈出的原生視窗中確認選中 `/Volumes`，點選 **“授權訪問”**。
3. 按鈕隨即更新為 **“外接磁碟取用權限已授予 ✓”**。
4. **授權效果**：解鎖對外接行動硬碟、USB 快閃記憶體盤、SD 卡、DMG 映像檔掛載點以及區域網 SMB/NFS/AFP 網路共享盤的讀寫許可權。

#### 第 4 步：選擇性單獨授權資料夾（靈活替代方案）
如果您不想直接授予廣泛的根目錄取用權限，完全可以跳過前兩步：

- 當您透過 ATBCmder 首次瀏覽未授權的目錄時，應用會自動捕獲許可權邊界，並彈出按需授權提示：
  `ATBCmder 需要您的授權以訪問：/Users/username/PrivateFolder`
- 點選“授予資料夾取用權限”，在系統面板中確認後，該目錄將被單獨永久書籤化。

#### 第 5 步：開啟“完全磁碟取用權限 (Full Disk Access)”以管理受保護的個人資料

> [!IMPORTANT]
> **沙盒書籤與完全磁碟取用權限 (FDA) 的區別**：
>
> - **沙盒書籤**：滿足 macOS 應用沙盒對常規檔案、資料夾及外部磁碟的讀寫要求。
> - **完全磁碟取用權限 (FDA)**：屬於 macOS TCC 隱私安全策略，用於保護高度私密的系統資料（如 Safari 歷史記錄、郵件附件、備忘錄、Time Machine 備份及各類系統級快取）。
> 
> 若您需要管理此類受系統級保護的隱私資料夾：
>
> 1. 在嚮導視窗中點選 **“開啟系統‘完全磁碟取用權限’設定…”**。
> 2. 系統將自動前往 **系統設定** → **隱私與安全性** → **完全磁碟取用權限**。
> 3. 點選鎖標或透過 Touch ID 驗證身份。
> 4. 找到 **ATBCmder** 並確保右側的開關處於 **開啟** 狀態。

### 如何撤銷或重置授權

如需重置所有沙盒授權書籤：

1. 點選選單欄 **配置** → **開啟配置目錄** (`cm_OpenConfigDirectory`)。
2. 找到並刪除 `sandbox_bookmarks.plist` 檔案。
3. 重啟 ATBCmder 即可。
4. 若需重置 macOS 系統級的 TCC 許可權記錄，在終端機機機機執行：
   ```bash
   tccutil reset SystemPolicyAllFiles com.aitobox.atbcmder
   ```

## 4. 多語言設定與主題外觀定製

ATBCmder 全面支援多語言本地化並深度契合 macOS 的視覺風格。

### 多語言動態切換

ATBCmder 內建支援 **30+ 種主流語言**，包括簡體中文、繁體中文、英語、德語、法語、西班牙語、俄語、日語、韓語、義大利語等。

![語言偏好設定](images/language_settings.png)

- **自動跟隨系統語言**：預設情況下，ATBCmder 會自動識別您 macOS 系統的當前語言環境 (`AppleLanguages`) 並呈現匹配的本地化介面。
- **手動選擇語言**：
  1. 按 `Cmd+,` 或執行 `cm_Options` 開啟偏好設定。
  2. 在左側導航欄中選擇 **語言 (Language)**。
  3. 在下拉選單中選取目標語言。
- **實時免重啟熱過載**：與許多修改語言後必須重啟的傳統 Mac 軟體不同，ATBCmder 支援即時熱更新——只要在下拉框中選定新語言，所有選單、按鈕提示、狀態資訊與對話方塊文字均會即刻完成熱替換。

### 外觀與深淺色模式

ATBCmder 完美適配 macOS 深淺色外觀：

- **隨系統外觀自動切換**：當您的 Mac 根據日落時間或控制中心在淺色與深色模式間切換時，ATBCmder 會平滑同步變色。
- **特色主題風格**：
  - **Fusion / macOS 原生風格**：經典的桌面設計，完整還原 macOS 強調色高亮與原生視覺通透感。
  - **Stylish 現代時尚風格**：融入現代膠囊控制元件、精緻分割陰影與平滑微動效。
  - **深色模式調色盤**：採用純正炭黑底色（`#2C2C2E` / `#242426`），配合高對比度文字排版與定製資料夾圖示，有效緩解暗光環境下的視覺疲勞。
  - **淺色模式調色盤**：清爽明亮的白灰色調（`#FAFBFD` / `#EEF2F7`），線條清晰分明。

## 5. ⚡ 高階技巧：個性化佈局與工作區持久化

充分釋放 ATBCmder 靈活的佈局潛力，為外接大屏、帶魚屏或垂直旋轉顯示器定製專屬工作空間：

### 技巧 1：鎖定儲存視窗位置與面板比例 (`cm_ConfigSavePos`)

當您精心調整好視窗大小、拖曳分割線設定好黃金比例後，可以將此佈局固定為預設啟動狀態：

1. 調整好 ATBCmder 視窗大小以及左右面板的分割比例。
2. 點選選單欄 **配置** → **儲存當前位置與佈局**，或執行內部指令：
   ```
   cm_ConfigSavePos
   ```

3. 視窗尺寸、螢幕座標、最大化狀態與分割線比例將立即固化寫入 `atbcmder.xml`。
4. 在 **偏好設定** → **佈局** 中勾選 **“退出時自動儲存視窗位置”**，即可讓軟體持續記憶每次關閉前的最後狀態。

### 技巧 2：一鍵切換上下水平雙面板 (`cm_HorizontalFilePanels`)

左右垂直分欄是檔案操作的標準佈局，但**上下堆疊水平分欄**在很多特殊場景下具有不可替代的優勢：

- 面對超長檔名，需要橫向展開完整閱讀時；
- 需同時比對許可權、所屬使用者、MD5 校驗值等多列超寬屬性時；
- 在豎屏旋轉顯示器或平板裝置上工作時。

切換方法極其簡單：

1. 點選選單欄 **顯示** → **水平雙面板**，或執行命令：
   ```
   cm_HorizontalFilePanels
   ```

2. 開啟後：
   - 雙面板立即變為上下排布（上方主面板與下方副面板）。
   - 中間快捷工具欄自動旋轉為橫向水平欄，穩穩鑲嵌在上下兩層之間。
   - 滑鼠懸停在中線時自動變為上下拖動指標 (`SplitVCursor`)，讓您隨心調整上下高度比例。

### 技巧 3：中間分割線快速吸附

- **秒級 50/50 歸中**：在中間工具欄或分割線上任意位置**雙擊滑鼠**，兩側面板立即精準恢復對等 50% 寬度。
- **常用比例切換**：在 Stylish 主題下，點選中間條上的膠囊按鈕可快速在 `50:50`、`70:30`（左側突出）或 `30:70`（右側突出）之間無縫切換。

### 技巧 4：智慧全域性會話記憶與工作區自動還原

ATBCmder 內建強勁的會話管理系統 (`SessionManager`)，確保每一次重新開啟應用，都能無縫接續上次的工作狀態：

- **自動持久化儲存**：會話狀態實時沉澱在配置目錄中的 `atbcmder_session.xml` 檔案中。
- **全方位空間記憶**：精準恢復視窗螢幕座標 (`x`, `y`)、長寬尺寸、最大化狀態以及左右面板的分割線配比 (`splitter_ratio`)。
- **分頁群組無感重現**：
  - 重啟後自動還原左右兩側面板中開啟的**全部分頁**。
  - 準確記憶退出前正處於啟用狀態的分頁索引。
  - 自動還原每個分頁對應的深層目錄路徑，徹底免去手動一層層重新點選尋找專案的煩惱。
- **設定初始預設位置**：透過選單欄 **配置 ➔ 儲存當前位置** (`cm_ConfigSavePos`)，您還可以隨時將當前狀態設為今後的基準預設模板。

## 6. 避坑指南：Mac 鍵盤功能鍵 (`Fn`) 正確配置

如果您曾經在 PC 鍵盤上使用過 Total Commander 或 Double Commander，您的手指通常習慣了第一排功能鍵的肌肉記憶（`F3` 檢視、`F4` 編輯、`F5` 複製、`F6` 移動、`F7` 新建、`F8` 刪除）。

但在 Mac 原生鍵盤上，這排按鍵在出廠預設狀態下有著不同的行為。

> [!WARNING]
> ### 🍎 macOS 功能鍵硬體功能衝突預警
> 在 Apple 鍵盤（包括 MacBook 自帶鍵盤與妙控鍵盤 Magic Keyboard）上，最頂排按鍵出廠預設被分配為 **macOS 專用硬體功能**（螢幕亮度、排程中心、聚焦搜尋、聽寫、勿擾模式、多媒體快進暫停以及系統音量）。
> 
> 如果您在一臺未做配置的 MacBook 上直接按下 `F5`，系統很可能會調節鍵盤背光亮度或啟動聽寫，而不是複製檔案！

### 方案 A：按住 `Fn`（或地球儀 🌐 鍵）組合觸發（預設體驗）
若您希望完整保留 Apple 頂欄原生的音量與亮度調節功能：

- 在按下對應功能鍵的同時，長按左下角的 **`Fn`**（或地球儀 🌐 鍵）：
  - `Fn+F3`：全能檢視器
  - `Fn+F4`：內建程式碼/文字編輯器
  - `Fn+F5`：複製檔案至對側
  - `Fn+F6`：移動檔案至對側
  - `Fn+F7`：新建資料夾
  - `Fn+F8`：安全刪除至廢紙簍

### 方案 B：全域性啟用“標準功能鍵”（強烈推薦）
若您追求原汁原味、單鍵極速響應的 Commander 操控快感，無需每次按住 `Fn`：

1. 點選螢幕左上角 Apple 圖示（），開啟 **系統設定**。
2. 在左側選單中選擇 **鍵盤**。
3. 點選右側的 **鍵盤快速鍵…** 按鈕。
4. 在左側列表中選中 **功能鍵**。
5. 開啟開關：**“將 F1、F2 等鍵用作標準功能鍵”**。

```
┌─────────────────────────────────────────────────────────────┐
│  鍵盤快捷鍵                                                 │
├──────────────────┬──────────────────────────────────────────┤
│  啟動臺與程式塢  │  將 F1、F2 等鍵用作標準功能鍵            │
│  顯示器          │                                          │
│  排程中心        │  [ 開啟 ───● ]                           │
│  鍵盤            │                                          │
│  輸入法          │  開啟此選項後，按住 Fn 鍵即可使用各個按  │
│  截圖            │  鍵上印製的多媒體控制功能。              │
│ ▸ 功能鍵         │                                          │
│  App 快捷鍵      │                                          │
└──────────────────┴──────────────────────────────────────────┘
```

開啟此設定後：

- 直接敲擊 `F1`–`F12` 即可瞬間觸發 ATBCmder 的全套核心指令。
- 若偶爾需要調節螢幕亮度或音量，只需按住 `Fn` 再按下對應鍵即可，兩全其美。

## 7. 雙矩陣高頻核心快速鍵速查表

ATBCmder 全面支援雙矩陣快速鍵生態：您既可以使用原汁原味的 macOS 快速鍵（`Cmd ⌘` 修飾鍵），也可以使用經典的 Commander 功能鍵（`Fn`），兩者並行不悖。

| 核心操作 | 命令 ID | macOS 原生快速鍵 (`Cmd ⌘`) | 經典 Commander 鍵 (`Fn`) | 功能描述 |
| :--- | :--- | :--- | :--- | :--- |
| **常用目錄書籤撥出** | `cm_DirHotList` | `Cmd+D` / `⌘D` | `Ctrl+D` / `⌃D` | 秒級撥出常用目錄書籤面板，支援模糊匹配即時直達。 |
| **驅動器切換 (左 / 右)** | `cm_LeftOpenDrives` / `cm_RightOpenDrives` | `⌥F1` / `⌥F2` (`⌥D`) | `Alt+F1` / `Alt+F2` (`Alt+D`) | 撥出左側或右側面板掛載驅動器與卷宗列表（`Alt+D` 為當前啟用面板）。 |
| **複製檔案** | `cm_Copy` | `Cmd+C` ➔ `Cmd+V` | `F5` (或 `Fn+F5`) | 將選中檔案從當前啟用面板複製到對側目標面板。 |
| **移動檔案** | `cm_Move` | `Cmd+C` ➔ `Opt+Cmd+V` | `F6` (或 `Fn+F6`) | 將選中檔案從當前啟用面板移動到對側目標面板。 |
| **全能檢視** | `cm_View` | `Space` / `Cmd+Y` | `F3` (或 `Fn+F3`) | 在全能檢視器中預覽檔案（程式碼、Hex、圖片、PDF、音影片等）。 |
| **對側快速預覽** | `cm_QuickView` | `Cmd+Q` / `Ctrl+Q` | `Ctrl+Q` | 直接在對側面板中實時開啟動態快速預覽。 |
| **編輯檔案** | `cm_Edit` | `Cmd+E` | `F4` (或 `Fn+F4`) | 在內建程式碼/文字編輯器中開啟並修改檔案。 |
| **新建資料夾** | `cm_MkDir` | `Shift+Cmd+N` | `F7` (或 `Fn+F7`) | 在當前面板中快速建立新資料夾。 |
| **刪除至廢紙簍** | `cm_Delete` | `Cmd+Backspace` | `F8` (或 `Fn+F8`) | 安全將選中檔案移至 macOS 系統廢紙簍。 |
| **行內快速重新命名** | `cm_Rename` | `Return` (回車) | `F2` / `Shift+F6` | 原地對當前游標高亮的檔名執行修改。 |
| **切換左右面板** | `cm_FocusSwap` | `Tab` | `Tab` | 瞬時輪轉切換鍵盤焦點至對側面板 (`cm_SwitchPanel`)。 |
| **互換左右路徑** | `cm_Exchange` | `Ctrl+U` | `Ctrl+U` | 保持標籤狀態，調換左右面板的當前目錄路徑。 |
| **新建分頁** | `cm_NewTab` | `Cmd+T` | `Ctrl+T` | 在當前面板中開啟一個新的目錄分頁。 |
| **關閉分頁** | `cm_CloseTab` | `Cmd+W` | `Ctrl+W` | 隨手關閉當前面板的活動分頁。 |
| **水平分欄模式** | `cm_HorizontalFilePanels` | 選單: 顯示 ➔ 水平雙面板 | 選單: 顯示 ➔ 水平雙面板 | 在左右垂直分欄與上下水平分欄排布間自由切換。 |
| **儲存當前佈局** | `cm_ConfigSavePos` | 選單: 配置 ➔ 儲存位置與佈局 | 選單: 配置 ➔ 儲存位置與佈局 | 固化當前視窗長寬尺寸與中線分割比例。 |
| **沙盒系統授權** | `cm_GrantFilesystemAccess` | 選單: 檔案 ➔ 授予許可權 | 選單: 檔案 ➔ 授予許可權 | 啟動 macOS App Sandbox 安全範圍檔案授權嚮導。 |
| **偏好設定** | `cm_Options` | `Cmd+,` | `Alt+O` | 開啟 ATBCmder 綜合偏好設定配置中心。 |
